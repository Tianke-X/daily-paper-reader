## 摘要
一个具有有限工作记忆的语言模型必须反复决定保留哪些存储项。每种部署的方法都在项到达时做出决定，基于过去（StreamingLLM, H2O）或基于对未来的猜测（SnapKV）。我们将此选择重新表述为对隐藏信号（项是否会被重用）的估计问题，将现有方法置于一个轴上，即提交滞后H：在线过滤器和学习预测器在H=0时提交，而Belady离线最优则在于已知整个未来。介于两者之间的缺失机制——固定滞后平滑——等待有限步数，观察正确的近未来预测所关注的项，然后才提交。这种测量（已证明的效用）将Belady不可观察的未来请求转化为我们可以从模型本身读取的内容。我们将其实例化为一种无训练策略RMM，它是H2O的严格泛化，当测量均匀时恰好退化为H2O。在重用是内生的且时间分离的受控设置中，已证明的效用识别出远优于累积注意力的使用记忆，并且小的有限记忆表现得像大得多的记忆。但在独立第三方基准测试中，运行在NVIDIA的KVPress框架内，与其自身的SnapKV、H2O和StreamingLLM实现进行比较，优势基本消失：RMM在单轮问答上与H2O相当，在流式多轮设置中则输给H2O和SnapKV。原因很简单：在自然文本上，模型对大多数词元是正确的，因此用正确性加权注意力几乎不改变它，并且除非重用是尖锐且内生的（标准基准测试未涉及），否则已证明的效用会坍缩为累积注意力。我们的贡献在于框架以及一份诚实的映射，说明何时测量优于累积，而非新的最优技术。

## Abstract
A language model with a bounded working memory must repeatedly decide which stored items to keep. Every deployed method decides the moment an item arrives, from the past (StreamingLLM, H2O) or from a guess about the future (SnapKV). We recast the choice as an estimation problem on a hidden signal, whether an item will be reused, placing existing methods on one axis, the commit lag $H$: online filters and learned predictors commit at $H=0$, while Belady's offline optimum sits where the whole future is known. The missing regime in between, fixed-lag smoothing, waits a bounded number of steps, observes which items a correct near-future prediction attended to, and only then commits. This measurement, demonstrated utility, turns Belady's unobservable future request into something we read off the model itself. We instantiate it as a training-free policy, RMM, a strict generalization of H2O that reduces to it exactly when the measurement is uniform. In controlled settings where reuse is endogenous and separated in time, demonstrated utility identifies used memory far better than accumulated attention, and a small bounded memory behaves like a much larger one. But on independent third-party benchmarks, run inside NVIDIA's KVPress harness against its own SnapKV, H2O, and StreamingLLM implementations, the advantage mostly disappears: RMM is on par with H2O for single-turn question answering and loses to both H2O and SnapKV in a streaming multi-turn setting. The cause is simple: on natural text the model is correct about most tokens, so weighting attention by correctness barely changes it, and demonstrated utility collapses onto accumulated attention unless reuse is sharp and endogenous, which standard benchmarks do not exercise. Our contribution is the framework and an honest map of when measuring beats accumulating, not a new state of the art.

## 1. 核心问题与整体含义（研究动机和背景）

语言模型在有限工作记忆（如KV缓存或循环状态）下运行时，必须反复决定保留哪些历史令牌、驱逐哪些。现有方法均在令牌到达时立即做出决策：要么基于过去信息（如StreamingLLM的最近性、H2O的累积注意力），要么基于对未来需求的猜测（如SnapKV）。这种即时决策的本质是一个估计问题：令牌的效用只有在未来被使用时才可知，而决策时缺乏证据。论文将驱逐问题重新框架化为一个带隐藏信号的估计问题，引入一个统一轴——**提交滞后H**（commit lag H）：在线过滤器与学习预测器属于H=0的极端，Belady离线最优则位于H→∞的极限。介于两者之间的**固定滞后平滑**（fixed-lag smoothing）在神经记忆领域尚未被探索。作者的核心动机是开辟这个中间地带：等待少量未来步数，观测模型实际关注了哪些令牌（即“已证明的效用”），之后再提交驱逐决策。这项工作的整体含义是提供一个理论框架来理解现有方法，并诚实地评估这一新机制在何时有用，而非声称新的最先进水平。

## 2. 方法论：核心思想、关键技术细节与算法流程

**核心思想**：将缓存驱逐问题视为一个状态估计问题，存在三个经典立场：滤波（利用过去与现在估计当前）、预测（估计未来）、平滑（利用到达更晚时间点的数据估计过去）。论文主张采用固定滞后平滑：对于每个令牌的保留/驱逐决策，延迟固定步数H，等到该令牌在近未来的实际使用情况已被观测到（而非猜测）后再做决定。这一转变将H=0的在线滤波/预测与H→∞的Belady离线最优统一在同一条轴上。

**关键技术细节**：
- **已证明的效用（Demonstrated Utility, DU）**：论文为Belady算法所需的未来请求序列构建了一个可观测替代物。对于一个缓存中的令牌k，在滞后窗口H内的已证明效用定义为：
  \[
  DU_H(k) = \sum_{t' \in (t_k, t_k+H]} \mathbb{1}[\text{prediction at } t' \text{ correct}] \cdot a(t' \rightarrow k)
  \]
  其中 \(a(t' \rightarrow k)\) 是位置 \(t'\) 对令牌 \(k\) 的注意力，正确性通过教师强制（teacher forcing）检查（模型在 \(t'\) 的顶层预测等于实际下一令牌）。该信号完全自监督，无需任何标签。与H2O的累积注意力 \(\sum_{t'} a(t' \rightarrow k)\) 相比，DU仅在每个注意项上乘以该位置预测是否正确。当所有预测都正确时，DU退化为H2O的分数；当模型高度正确时，两者接近一致。

- **RMM策略**：一种无训练（training-free）的固定滞后平滑策略。每个新到的令牌先进入一个大小为H的暂存缓冲区（provisional buffer），尚未提交。在缓存期间仍可被后续查询读取。当令牌年龄达到H时，根据其已证明效用是否超过当前提交缓存中的最弱项来决定是提交（保留）还是驱逐。总缓存容量为 \(K+H\)（K为提交缓存大小，H为缓冲区）。由于DU可直接从注意力与正确性计算，RMM可在冻结模型上无训练部署，并严格泛化H2O：当正确性权重为常值时恰好退化为H2O。

**算法流程（文字说明）**：
1. 每个新令牌到达时，放入大小为H的暂存缓冲区（同时可被后续读取）。
2. 对于缓冲区中年龄已满H的令牌，计算其DU，即对其出现后H窗口内所有位置的注意力求和，并按该位置预测是否正确加权。
3. 比较该令牌的DU与当前已提交缓存K个令牌中的最小DU值；若更大则将其提交到缓存（可能驱逐一个）（或按排序保留top-K；实际上文中描述为“如果它的DU超过最弱的已提交项则提交，否则驱逐”，等价于保持提交缓存按照DU排序，只保留前K个）。
4. 提交缓存始终维护具有最高DU的K个令牌（已超出滞后窗口的），暂存缓冲区持有最近的H个未决令牌。
5. 推理时，模型从提交缓存和暂存缓冲区中读取键值对。

## 6. 论文的主要结论与发现

1. **框架价值**：将驱逐问题重新框架为估计问题，以提交滞后H为统一轴，连接了在线过滤器、预测器和Belady离线最优。这一视角是论文的主要理论贡献。
2. **Belady桥接**：提出**已证明的效用**（demonstrated utility）作为Belady未来请求序列的标签无关替代物，将不可观测的预测问题转化为可观测的测量问题。
3. **RMM策略属性**：RMM是H2O的严格泛化，当正确性加权均匀时退化为H2O，因此至少达到H2O类性能。
4. **受控环境下的显著优势**：当重用是内生的、时间上分离时，已证明的效用识别有用令牌的能力远优于累积注意力（多跳推理中约0.8 vs 0.1；流式agent中保留率接近无界Oracle），有界小记忆可表现得像大得多的记忆。
5. **独立基准上的持平/劣化**：在自然文本的单轮任务中，由于模型正确率很高（~0.85-0.90），正确性加权几乎均匀，RMM与H2O统计上无差异；在流式多轮对话中，RMM反而输给H2O和SnapKV。原因是缓存基于之前正确答案关注的部分进行索引，而下一轮独立问题不一定需要这些部分。
6. **根本原因**：已证明的效用与累积注意力在大多数自然文本上重合，因为模型预测多数令牌正确；两者只有在正确性具有选择性和局部性（即重用尖锐且内生）时才产生差异，而标准基准没有包含这种模式。
7. **诚实结论**：论文的持久贡献是框架，而非新的最优性能。它提供了一个关于“何时测量优于累积”的清晰图谱，并指出了当前基准的不足。

## 8. 不足与局限

- **独立基准表现不优**：在标准自然语言理解基准上，RMM未优于H2O，并且在流式设置中反而更差。因此它不能作为现有方法的即插即用改进。
