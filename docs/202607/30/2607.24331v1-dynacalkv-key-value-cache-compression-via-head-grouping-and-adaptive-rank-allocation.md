## 摘要
随着大语言模型推理阶段需要处理长上下文窗口，键值缓存最初似乎能应对这一挑战，但随着上下文窗口的持续增长，它最终会成为显著瓶颈。低秩压缩最近被研究作为减少键值缓存内存同时保持模型性能的有效方法。然而，尽管键缓存和值缓存具有不同作用，现有方法中只有少数对它们加以区分。此外，这些方法通常采用固定的注意力头部分组，这可能无法充分利用注意力头部之间的结构相似性。本文提出了一种改进的低秩键值缓存压缩框架。对于键缓存，我们基于中心核对齐相似性动态分组注意力头部，并在参数预算下自适应分配秩预算。对于值缓存，我们采用与ReCalKV相同的方法，通过离线校准改进低秩分解以提升重建质量。在三个指令微调大语言模型上的实验结果表明，我们的方法在保持竞争性准确率的同时减少了键缓存参数数量。我们进一步观察到，所提出的策略对多头注意力模型特别有效，而对于分组查询注意力模型，尤其是在长上下文场景下，应更保守地应用。

## Abstract
As the inference phase of Large Language Models (LLMs) requires handling long context windows, the Key-Value (KV) cache initially appears to address this challenge but eventually becomes a significant bottleneck as the context window continues to grow. Low-rank compression has recently been studied as an effective approach to reduce KV cache memory while maintaining model performance. However, only a few existing methods treat the Key and Value caches differently, despite their distinct roles. Moreover, these methods typically employ fixed attention-head grouping, which may not fully exploit the structural similarity among attention heads. In this paper, we propose an improved low-rank KV cache compression framework. For the Key cache, we dynamically group attention heads based on Centered Kernel Alignment (CKA) similarity and allocate the rank budget adaptively under a parameter budget. For the Value cache, we adopt the same approach as ReCalKV, refining the low-rank decomposition through offline calibration to improve reconstruction quality. Experimental results on three instruction-tuned LLMs show that our method reduces the number of Key cache parameters while maintaining competitive accuracy. We further observe that the proposed strategy is particularly effective for Multi-Head Attention (MHA) models, whereas it should be applied more conservatively to Grouped-Query Attention (GQA) models, especially in long-context settings.

## 1. 核心问题与整体含义

**研究动机与背景**  
大语言模型（LLM）推理时，Key-Value (KV) 缓存用于存储已生成 token 的注意力表示，以避免重复计算。然而，随着上下文窗口增长，KV 缓存内存线性增长成为严重瓶颈。低秩压缩是近期有效的内存缩减方法，但现有工作存在两个不足：  
- 未充分区分 Key 和 Value 缓存的不同角色（Key 主要作为索引，Value 包含完整信息），导致压缩策略过于统一；  
- 注意力头分组采用固定大小（如每组4头），未能利用头之间的结构相似性进行自适应划分。  

**论文目标**  
提出 DynaCalKV，一种动态头分组 + 自适应秩分配的低秩 KV 缓存压缩框架，在减少 Key 缓存参数的同时保持模型性能，并针对不同注意力架构（MHA vs. GQA）给出使用建议。

## 2. 方法论

### 核心思想
- **Key 缓存**：基于 Centered Kernel Alignment (CKA) 相似度动态聚类注意力头，形成可变大小的头组；然后根据各组能量（奇异值平方和）初始化秩，并通过贪心调整满足参数预算约束。  
- **Value 缓存**：沿用 ReCalKV 的离线校准方法，在 SVD 分解后用校准数据微调左/右因子，以最小化重建误差。

### 关键技术细节
1. **层间秩分配**：借鉴 Palu，使用 Fisher Information 在层间分配总秩预算。
2. **Key 压缩（算法1）**：
   - 输入：投影矩阵 W<sup>(k)</sup>、CKA 相似度矩阵 S、秩预算 r、候选聚类数 K。
   - 步骤：
     - 对每个 K，用层次聚类将 h 个注意力头分成 K 组，得到子矩阵 {W<sub>i</sub>}。
     - 初始化秩 r<sub>i</sub> ∝ 该组能量（奇异值平方和），并四舍五入。
     - 通过贪心调整，每次减少归一化能量损失最小的组的秩，直到满足参数约束：∑ r<sub>i</sub>α<sub>i</sub> ≤ 4r/h（其中 α<sub>i</sub> = h<sub>i</sub>/h）。
     - 对每组进行低秩分解 W<sub>i</sub> ≈ L<sub>i</sub>R<sub>i</sub>。
     - 选择使重建误差 + λ·秩利用惩罚（λ=1）最小的聚类数 K*。
3. **Value 压缩**：
   - 对完整 W<sup>(v)</sup> 做 SVD 低秩分解，得到 L<sub>v</sub>, R<sub>v</sub>。
   - 使用校准数据 X 交替更新 L<sub>v</sub> 和 R<sub>v</sub>：  
     L<sub>v</sub> = W<sup>(v)</sup>XX<sup>⊤</sup>R<sub>v</sub><sup>⊤</sup>(R<sub>v</sub>XX<sup>⊤</sup>R<sub>v</sub><sup>⊤</sup>)<sup>−1</sup>，  
     R<sub>v</sub> = (L<sub>v</sub><sup>⊤</sup>L<sub>v</sub>)<sup>−1</sup>L<sub>v</sub><sup>⊤</sup>W<sup>(v)</sup>。

### 算法流程（文字说明）
- 离线阶段：对每层 Key 投影矩阵，计算 CKA 相似度；遍历候选聚类数 K，执行聚类 → 初始秩分配 → 贪心调整 → 分解 → 计算损失；选择最优 K 对应的分解结果。Value 则执行 SVD 后离线校准。
- 推理阶段：仅使用已压缩的因子 L<sub>i</sub>, R<sub>i</sub> 和 L<sub>v</sub>, R<sub>v</sub>，无额外开销。

## 6. 主要结论与发现

1. **参数减少显著**：Key 缓存参数相比 ReCalKV 减少 16%–65%，减少幅度与头维度成反比（dh=64 的模型减少更多），且组越大减少越多。
2. **零样本准确率保持**：平均准确率变化微小（Llama-3.2 降 0.15%，Qwen1.5 降 0.81%，SmolLM2 升 0.44%），在常识任务（PIQA, ARC-e）上有提升，复杂推理任务略有下降。
3. **长上下文差异**：  
   - **MHA 模型（Qwen1.5）**：仅降 1.02 分，部分任务甚至提升，表现稳健。  
   - **GQA 模型（Llama-3.2）**：平均下降 8.03 分，检索和摘要任务损失严重。表明 DynaCalKV 对 GQA 长上下文场景需谨慎使用。
4. **架构依赖**：动态分组对高头数的 MHA 模型最有效；对已用少量 Key 头的 GQA 模型，进一步聚类会过度压缩关键信息。

## 7. 优点

- **方法创新性**：首次将 CKA 相似度动态聚类用于 Key 头分组，并引入能量驱动的自适应秩分配 + 参数预算约束贪心调整。
- **效率与性能平衡**：在参数大幅减少的同时保持竞争性准确率，且离线计算无推理开销。
- **架构敏感性分析**：明确指出了 MHA 与 GQA 的不同适用性，给出实用建议。
- **实验设计**：短上下文 + 长上下文双重验证，且对比基线基于同一代码库，公平性较好。
- **可解释性**：图1直观展示不同模型的头分组结构，帮助理解参数减少差异。

## 8. 不足与局限

- **硬件限制**：仅在 1B 级小模型上测试，结论对更大模型（需更大内存和更长上下文）的泛化性未知。
- **缺乏消融实验**：未单独验证“动态分组” vs “固定分组”或“自适应秩分配” vs “均匀分配”的贡献。

- **长上下文数据集缺失**：SmolLM2 因性能极低被排除，无法验证 MHA 模型在长上下文上的表现（仅 Qwen1.5 一个 MHA 模型）。
