## 摘要
复杂的结构化推理任务通常需要额外的计算，而当前的语言模型主要通过增加参数规模或将中间步骤序列化为思维链(CoT) token 来获得这种计算。前者提高了训练和部署成本，后者则将推理计算与自回归输出长度绑定。我们提出 Penelope，一种高效的潜推理框架，适用于预训练的解码器-only Transformer，将循环计算局部化到选定的解码器区间。下层的解码器前缀被评估一次以构建问题条件边界记忆，然后通过时间调制的GRU动态和循环读出状态在答案生成之前进行迭代精炼。一种渐进式的 CoT-to-latent 课程将可见推理转移到这个内部循环路径，从而允许在潜空间中分配额外计算，而无需重复执行完整的解码器或生成冗长的中间轨迹。在开源结构化推理基准上的实验表明，在验证选择的潜预算下，Penelope 在达到与已建立的潜推理模型相当的准确性的同时，降低了测量推理延迟。这些结果表明，潜精炼可以局部化到较窄的解码器区间，减少了重复的全解码器执行，无需生成长的可视推理轨迹，为解码器-only Transformer模型提供了实用的准确率-效率权衡。

## Abstract
Complex structured reasoning tasks often require additional computation, yet current language models obtain it mainly by increasing parameter scale or by serializing intermediate steps as chain-of-thought (CoT) tokens. The former raises training and deployment costs, while the latter ties reasoning computation to autoregressive output length. We introduce Penelope, an efficient latent-reasoning framework for pretrained decoder-only Transformers that localizes recurrent computation to a selected decoder interval. The lower decoder prefix is evaluated once to construct a problem-conditioned boundary memory, which is then iteratively refined through time-modulated GRU dynamics and recurrent readout states before answer generation. A progressive CoT-to-latent curriculum transfers visible reasoning into this internal recurrent path, allowing additional computation to be allocated in latent space without repeatedly executing the complete decoder or generating a long intermediate trace. Experiments on open-source structured-reasoning benchmarks show that, at validation-selected latent budgets, Penelope attains competitive accuracy relative to established latent-reasoning models while reducing measured inference latency. These results show that latent refinement can be localized to a narrow decoder interval, reducing repeated full-decoder execution without generating a long visible reasoning trace and providing a practical accuracy-efficiency tradeoff for decoder-only Transformer models.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：复杂结构化推理任务（如表达式归约、逻辑推理）需要大量计算。现有方法主要通过两条路径获得额外计算：
  - **增大模型参数规模**：提高训练和部署成本。
  - **显式思维链（CoT）**：将中间推理步骤序列化为生成的 token，引入额外自回归步数，导致推理长度与计算量耦合，生成长序列。
- **动机**：寻求一种既不依赖大模型也不依赖长 CoT 序列的推理计算分配方式，即**在潜在空间（latent space）中进行高效迭代精炼**，避免重复执行完整解码器。
- **整体含义**：Penelope 提出一种局部化循环计算框架，将循环限制在选定的窄解码器区间内，通过一次式下前缀处理 + 多次局部循环 + 最终答案生成，实现推理精度与延迟的更好权衡。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- **局部化循环（Localized Recurrence）**：将解码器分为三段：下层前缀 `F[0:ℓs)`、循环区间 `F[ℓs:ℓe)`、最终接口区间 `F[ℓs:L)`。下层前缀只执行一次，循环区间多次执行（参数共享），最终接口执行一次。
- **边界记忆与读出状态**：通过固定数量的**锚点（anchors）** 和**读出锚点**，构成问题条件化的持续接口，循环区间仅迭代这些固定大小的状态。
- **时间调制与门控更新**：使用时间网络生成调制参数（γ, β, s）和门控系数（gt = 0.5αt），结合 GRU 进行记忆更新。
- **渐进式训练课程（Progressive Latent Training）**：从可见 CoT 出发，逐步将可见推理步骤替换为潜在循环步，最终仅生成答案。

### 关键技术细节
- **架构分解**：解码器 F = F[ℓe:L) ∘ F[ℓs:ℓe) ∘ F[0:ℓs)。循环区间宽度 r = ℓe - ℓs（实验中使用 r = 5，ℓs = 11，ℓe = 16，L = 16）。
- **初始构建**：一次式运行下层前缀，对 prompt 和锚点编码，得到边界状态 Hx、初始记忆 M0、初始读出 R0。同时构建循环区间 prompt-side KV 缓存 Cx。
- **循环精炼（K 步）**：
  - 第 t 步：将 M_{t-1} + G + e_t 作为查询，通过循环区间（使用 Cx）得到 Hlat_t。
  - 时间网络 gτ 生成调制参数（γ, β, s）进行特征调制和残差适配（Aφ）。
  - GRU_M 计算候选记忆 fMt，然后门控更新：Mt = M_{t-1} + 0.5αt(fMt - M_{t-1})。
  - 读出 GRU_R 根据 Hlat_t 的均值更新 Rt。
- **答案生成**：K 步后，将 MK 和 RK 作为查询通过 F[ℓs:L) 一次，结果追加到 prompt 缓存中，然后标准自回归解码生成答案。

### 算法流程（文字描述）
```
1. 输入 x → 嵌入 X
2. 下层前缀执行: [Hx, M0, R0] = F[0:ℓs)([X; A+G; Q])
3. 构建 Cx = KV缓存[ℓs:ℓe)(Hx) （一次）
4. 对于 t = 1..K:
   - 调制：根据 t 获取 (γ, β, s)
   - 通过循环区间查询：Hlat_t = F[ℓs:ℓe)(M_{t-1}+G+e_t; Cx) 
   - 时间调制、残差适配、GRU更新记忆得到 Mt
   - 读出更新：Rt = GRU_R(mean(Hlat_t)+eR_t, R_{t-1})
5. 最终接口：将 [MK; RK] 通过 F[ℓs:L) 合并到缓存
6. 自回归解码生成答案
```

## 6. 主要结论与发现

1. **精度相当，延迟降低**：在三个任务上 Penelope 的 EM 与 Coconut 相当（差距 <1%），但推理延迟降低 33%~56%。
2. **局部化循环有效**：输出侧区间（[11,16)）的循环与全解码器循环精度差距仅 0.27%，但解码层应用次数减少 2.51 倍（51 vs 128）。
3. **渐进式训练成功**：从 CoT 逐步转移到潜在循环，使得模型能够适应局部化推理。
4. **门控机制有益**：直接覆盖记忆导致 EM 下降约 0.8 点，验证了时间调制和门控更新的重要性。
5. **K=0 基线显示小增益**：推理-only K=0 与完整循环相比平均增益 0.69%，说明循环能纠正部分边界错误，但非单调。
