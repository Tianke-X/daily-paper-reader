## 摘要
基于图的检索增强生成越来越依赖多跳检索，其中回答一个查询需要组合多个连接的知识图谱三元组。然而，现有的检索器通常通过全局语义匹配独立地对三元组进行排序。此外，许多多跳基准只提供最终答案，这限制了对查询-三元组对齐的监督，并导致结构上必要但弱对齐的事实被遗漏。为了解决这些问题，我们提出了一种知识对齐的多跳检索器KAMR，它能够区分由查询强烈约束的锚点三元组和那些虽与锚点结构相连但弱对齐的三元组。为了缓解缺乏查询-三元组对齐监督的问题，我们通过掩码三元组元素并提示LLM生成相应查询来构建部分对齐数据集，并优化两个对比目标用于对级和元素级匹配。在推理时，KAMR全局检索锚点，然后局部扩展以收集连接的证据。在四个基准、三个LLM骨干和十四个基线中，KAMR持续改进了多跳检索和下游问答性能。

## Abstract
Graph-based retrieval-augmented generation increasingly relies on multi-hop retrieval, where answering a query requires composing multiple connected knowledge-graph triplets. However, existing retrievers often rank triplets independently via global semantic matching. Moreover, many multi-hop benchmarks provide only final answers, which limits supervision for query--triplet alignment and causes structurally necessary but weakly aligned facts to be missed. To address these issues, we propose a knowledge-aligned multi-hop retriever, KAMR, which distinguishes anchor triplets that are strongly constrained by the query from connected triplets that are weakly aligned yet structurally linked to the anchors. To mitigate the lack of query-triplet alignment supervision, we build a partial alignment dataset by masking triplet elements and prompting an LLM to generate corresponding queries, and optimize two contrastive objectives for pair-level and element-level matching. At inference time, KAMR retrieves anchors globally and then expands locally to collect connected evidence. Across four benchmarks, three LLM backbones, and fourteen baselines, KAMR consistently improves multi-hop retrieval and downstream question answering performance.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：基于知识图谱的多跳检索增强生成（Graph RAG）中，现有检索器采用全局语义匹配独立排序三元组，导致两类关键证据被遗漏：
  - **锚点三元组（Anchor Triplets）**：与查询强语义对齐（如实体-关系对完全匹配）。
  - **连接三元组（Connected Triplets）**：与查询弱对齐，但通过实体与锚点结构相连，对多跳推理不可或缺。
- **更深的挑战**：多跳基准数据集（如CWQ）只提供最终答案，缺乏查询-三元组对齐的显式监督，使得模型难以学习区分两类三元组。
- **论文目标**：设计一种知识对齐的多跳检索器（KAMR），显式建模部分对齐与结构连通性，在无显式多跳标注下提升检索质量，从而改善下游问答生成。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
- **区分两类检索目标**：
  - **锚点三元组**：查询中指定了2个元素（例如实体+关系），强约束。
  - **连接三元组**：查询只指定1个元素，通过共享实体与锚点/已检索链相连。
- **两阶段推理**：先全局检索锚点，再在局部图邻域中迭代扩展连接三元组。
### 关键技术细节
1. **部分对齐数据集构建**：
   - 对知识图谱中的每个完整三元组 (h, r, t)，通过掩码一个元素得到三个部分三元组：{(h, r), (r, t), (h, t)}。
   - 使用LLM（LLaMA-3.1-8B-Instruct）将每个部分三元组转化为自然语言查询，构成配对数据集 U = {(q_i, u_i)}。
   - 总共合成840,875个查询-部分三元组对，与下游任务无重叠。
2. **预训练损失设计**（公式2-5）：
   - **锚点预训练损失 L_a**：InfoNCE损失，对齐查询编码 q_i 与部分三元组编码 u_i（两元素拼接）。
   - **连接预训练损失 L_c**：InfoNCE损失，对齐查询编码与单个元素编码（元素级对比），使模型能识别与查询仅有单一元素重叠的三元组。
3. **推理阶段的两阶段检索**（算法1）：
   - **阶段1（锚点检索）**：对每个候选三元组，计算查询与三个部分三元组相似度的最大值，选Top-M作为锚点集 A_q。
   - **阶段2（迭代扩展）**：从锚点出发，在g跳邻域内筛选与查询恰好共享一个元素、且与当前证据集有实体连接的三元组；对每个候选，除去共享实体后，用剩下的两个元素与查询计算元素级最大相似度；迭代加入Top候选，直到检索预算K或达到迭代次数N。
   - 最终证据集 T_q = A_q ∪ C_q，其中 |A_q|=M, |C_q|=K-M。
### 关键公式：
- 预训练总损失：L = L_a + L_c
- L_a = -1/|B| Σ_i log[exp(sim(q_i, u_i)/T) / Σ_j exp(sim(q_i, u_j)/T)]
- L_c = -1/(2|B|) Σ_{i,k} log[exp(sim(q_i, e_ki)/T) / Σ_{j,k'} exp(sim(q_i, e_k'j)/T)]
