## 摘要
自主任务本质上具有长时域和多轮交互的特点，通过与环境互动不断累积上下文。现有的上下文压缩方法不可避免地会造成信息损失，且由僵化的启发式规则触发，导致其与智能体不断变化的推理重点脱节。我们提出自主上下文管理（ACM）框架，该框架为智能体配备专门设计的上下文编辑工具，以实现无损上下文管理。受人类短期和长期记忆交互的启发，智能体自主决定何时压缩其上下文，将丢弃的内容卸载到外部记忆系统，并在需要时按需查询以进行后续检索。基于这一框架，我们进一步开发了一个后训练流水线，构建高质量的上下文管理示范，并在自主搜索和编码任务上提升模型性能。进一步分析表明，有效的上下文管理可降低峰值令牌压力，支持更长的探索，并在独立试验中产生更一致的解决方案。代码、数据和模型检查点可在 https://github.com/lixiaochuan2020/agentic-context-management 获取。

## Abstract
Agentic tasks are inherently long-horizon and multi-turn, constantly accumulating context through interactions with the environment. Existing context compression methods inevitably incur information loss and are triggered by rigid heuristic rules, leaving them misaligned with the agent's evolving reasoning focus. We propose Agentic Context Management (ACM), a framework that equips agents with purpose-built context editing tools for lossless context management. Inspired by the interaction between short-term and long-term human memory, the agent autonomously decides when to compress its context, offloads discarded content to an external memory system, and queries it on demand for later retrieval. Building on this framework, we further develop a post-training pipeline that constructs high-quality demonstrations of context management and improves model performance on both agentic search and coding tasks. Further analysis reveals that effective context management reduces peak token pressure, enables extended explorations, and yields more consistent solutions across independent trials. Code, data, and model checkpoints are available at https://github.com/lixiaochuan2020/agentic-context-management.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：大语言模型（LLM）驱动的智能体在执行长时域、多轮交互的自主任务时，会不断累积交互轨迹（推理、工具调用、环境反馈），导致上下文窗口迅速膨胀，即使模型支持百万级 token 名义窗口，实际性能仍会显著下降（“Lost in the Middle” 等问题）。
- **现有局限**：已有方法包括长上下文预训练、混合注意力、启发式压缩（截断、摘要、固定阈值触发），但都存在信息损失、触发规则僵硬、与模型推理过程脱节等缺陷，无法适应智能体不断变化的推理重点。
- **核心问题**：如何让智能体自主、无损地管理其上下文，模拟人类短期记忆（工作记忆）与长期记忆（外部存储）的交互机制，从而在保持上下文紧凑的同时保留所有历史信息用于按需检索。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想（ACM 框架）**：受 Atkinson-Shiffrin 人类记忆模型启发，将上下文分为“短期工作记忆”（当前对话历史）和“长期记忆”（外部磁盘存储）。智能体配备两种工具：
  - `manage_context`：将之前所有消息压缩为简洁摘要（由 LLM 生成），同时将原始消息无损保存到外部文件（含唯一 summary_id），压缩后的摘要替换原上下文，系统提示和原始问题保留。
  - `query_memory`：通过 summary_id 查询对应的原始消息，由 LLM 返回与查询相关的信息。
- **关键特性**：压缩是 **无损**（原始消息可恢复）且 **智能体自主触发**（非启发式规则），从而与推理状态同步，降低峰值 token 压力。
- **训练数据生成（双约束教师-学生框架）**：
  - **Phase 1（学生展开）**：学生模型分别在有/无 ACM 工具条件下完成任务，得到轨迹 H⁺（有工具）和 H⁻（无工具）。
  - **Phase 2（教师标注）**：教师模型（更强的同族模型）收到两种指导提示：
    - **注入（对 H⁻）**：识别需要压缩的位置（冗余搜索、死循环等），插入 `manage_context` 调用。
    - **精炼（对 H⁺）**：识别不恰当压缩（过早压缩或应提交答案），替换为搜索、获取文档或提交答案等更合适的动作。
  - **目标函数**：采用 **在线策略蒸馏**（on-policy distillation），学生优化与教师 top-K token 分布的 KL 散度，仅对助手 token 计算损失，系统提示、用户输入、工具输出 token 被掩码。
  - **质量过滤**：仅保留学生未成功完成所有试验的轨迹（确保从困难案例学习），并验证教师推理未泄漏参考答案。
- **公式**（损失函数）：

    ```
    L_ACM(θ) = -E_{τ~π_θ} [ Σ_{t∈T_a(τ)} Σ_{v∈V} p_T(v|s;h_{<t}) log π_θ(v|s;h_{<t}) ]
    ```

    其中 p_T 是教师 top-K 候选 token 的重归一化分布，π_θ 是学生分布，h_{<t} 是历史。

## 6. 论文的主要结论与发现

- ACM 框架显著提升性能：在 BrowseComp-Plus 上 Pass@1 从 57.0%（ReAct）提升至 72.7%（ACM-Post-Trained），相对提升 27%；DeepSearchQA 从 36.7% 升至 42.5%；SWE-Bench Verified 从 48.9% 升至 53.0%。接近 40 倍更大的开源模型。
- **峰值 token 压力降低**：平均峰值 token 减少约 20%，KV 缓存开销下降。
- **更长的有效探索**：工具调用次数增加，搜索覆盖更广。
- **更一致的结果**：Pass@4 与 Pass 4 差距缩小，独立试验间更稳定。
- **上下文动态特征**：ACM 形成锯齿状上下文增长模式，压缩早于上下文极限触发，而 ReAct 线性增长直至极限。
- **训练必要性**：即使强模型（GPT-5.5）也很少自主使用上下文管理，需要针对性训练数据。蒸馏与 ACM 数据结合最佳。
