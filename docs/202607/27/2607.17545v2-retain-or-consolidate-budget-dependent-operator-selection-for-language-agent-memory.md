## 摘要
语言智能体在交互过程中依赖记忆。然而，大语言模型的有限上下文窗口及其推理成本限制了单次可使用的记忆量。现有系统主要遵循两种策略：记忆保留和记忆整合。保留策略保持原始记录并保留精确细节，但在严格预算下相关证据可能无法容纳；整合策略压缩并合并记录，提高每token的覆盖范围，但可能丢失查询关键细节。没有一种策略普遍更优。这引出了两个核心问题：何时整合应取代保留？以及应选择哪个操作符——合并、抽象或重写？我们通过将每个操作符的效用分解为对保留策略遗漏证据的覆盖效应和对已容纳原始证据的符号替代效应，来形式化这一决策。两者的平衡解释了为何偏好行动随相对预算压力变化而变化。我们通过离线抽象-安全（OAS）机制实现该机制，这是一种轻量级学习器，利用预生成特征和保留集外危害校准来估计行动效用。公开的LongMemEval和LoCoMo基准测试展示了相同的预算依赖模式。在LongMemEval上，严格预算下整合可将绝对准确率提升48%，而宽松预算下保留更优；LoCoMo在较小预算下复制了这种交叉现象，与其更短的证据一致。在两个数据集上，当需要压缩时，跨笔记抽象和合并通常优于局部重写。

## Abstract
Language agents depend on memory across interactions. However, the limited context windows of large language models (LLMs) and their inference costs constrain how much memory can be used at once. Existing systems mainly follow two strategies: memory retention and memory consolidation. Retention keeps raw records and preserves exact details, but relevant evidence may not fit under a tight budget; consolidation compresses and combines records, improving coverage per token but risking the loss of query-critical details. Neither strategy is universally preferable. This raises two central questions: when should consolidation replace retention, and which operator -- Merge, Abstract, or Rewrite -- should be selected? We formalize this decision by decomposing each operator's utility into a coverage effect on evidence omitted by retention and a signed replacement effect on raw evidence that already fits. Their balance explains why the preferred action changes with relative budget pressure. We implement this mechanism with Offline Abstraction-Safety (OAS), a lightweight learner that estimates action utilities from pre-generation features with held-out harm calibration. The public LongMemEval and LoCoMo benchmarks show the same budget-dependent pattern. On LongMemEval, consolidation improves absolute accuracy by up to 48% under tight budgets, whereas retention is preferable under loose budgets; LoCoMo replicates this crossover at a smaller budget, consistent with its shorter evidence. On both datasets, cross-note abstraction and merging generally outperform local rewriting when compression is necessary.

- **研究动机**：语言智能体（Language Agents）依赖记忆来存储历史交互信息，从而支持未来的推理与行动。然而，大语言模型（LLM）的有限上下文窗口和推理成本限制了单次可使用的记忆量。现有记忆管理面临两种策略的取舍：
  - **保留（Retention）**：忠实保留原始记录，但预算紧张时可能无法容纳所有相关证据。
  - **整合（Consolidation）**：通过压缩、合并或重写生成紧凑表示，提高每 token 的证据覆盖率，但可能丢失关键细节或引入错误。
- **核心问题**：何时应该用整合替换保留？当需要整合时，应选择哪个操作符（Merge / Abstract / Rewrite）？即“何时（when）”与“哪个（which）”的联合决策问题。
- **整体含义**：最优决策依赖于预算压力（budget pressure）与证据结构，而非固定的 token 阈值。作者通过分解整合效用为覆盖效应与替换效应，解释了偏好的动态变化，并提出了可学习的路由机制 OAS。

## 2. 论文提出的方法论

### 核心思想
- 将保留与三种生成性整合操作符（Merge、Abstract、Rewrite）视为有限、预算依赖的动作集合。
- 每个动作的预期回答效用定义为条件期望。通过引入一个理想化的代理效用模型，将整合的价值分解为：
  - **覆盖效应（Coverage Effect）**：整合操作补充了保留遗漏的查询（占用了新证据）。
  - **替换效应（Replacement Effect）**：整合操作替换了已存在于保留中的原始证据，可能导致正或负的贡献（取决于生成表示相对于原件的保真度）。
- 预算减少会收缩保留的“原始证据覆盖区域”，从而增大覆盖效应的潜在收益；当预算充足时，替换效应可能占主导，使保留更优。

### 关键技术细节
- **动作空间**：A = {ret, Merge, Abstract, Rewrite}。保留（ret）不修改原始证据；Merge 将多个笔记合并为一个紧凑的事实性记录；Abstract 合成一个高层级笔记；Rewrite 独立改写每个笔记后打包。
- **形式化定义**：给定实例 z = (M, C, q, B)，定义整合增益 Δo(z) = uo(z) - uret(z)，其中 u 是二元效用（0/1），由固定裁判评估答案。最优策略选择最大化条件期望 μa(z) 的动作。
- **代理效用模型**：使用简化的代理函数 U_B(M) = E_F[s_B(q,M)]，其中 s_B 是带符号的保真度贡献。在假设局部化检索变化下，推导出 ΔU_{B,o} = 覆盖效应 + 替换效应（见 Proposition 1）。
- **离线抽象-安全学习（OAS）**：
  - **特征工程**：11 维特征，包括归一化预算、包含笔记数、token 压力、预算拟合分数、会话数、不一致性代理、平均余弦相似度、查询类型 one-hot。
  - **效用回归**：为每个动作 a 训练岭回归模型（线性响应），预测 μ̂_a(z)。使用分组交叉验证选择正则化强度。
  - **决策规则**：选择预测效用最大的动作（Direct OAS）。Calibrated OAS 在验证集上对每个预算选择安全阈值（零有害选择），仅当预测优势超过阈值时选择整合。
  - **理论保证**：如果预测效用与真实期望误差 ≤ ϵ，则决策遗憾 ≤ 2ϵ（Proposition 3）。

1. **预算交叉**：整合在紧预算（32/64 tokens）下显著优于保留（LongMemEval 上 Abstract 提升 48%），而保留在松预算（256 tokens）下优于所有整合操作（约 8-11%）。LoCoMo 在更小预算下重现了交叉，表明相对预算压力（evidence-fit 比例）而非绝对 token 数是关键驱动力。
2. **操作符选择**：在需要压缩时，跨笔记的 Abstract 和 Merge 普遍优于局部 Rewrite；但 Abstract 与 Merge 之间并无显著性差异，哪个更优取决于实例。
3. **机制验证**：拟合分层的诊断（Table 1）证实了覆盖效应与替换效应的存在：当保留部分拟合时整合带来帮助，当完全拟合时整合带来伤害。
