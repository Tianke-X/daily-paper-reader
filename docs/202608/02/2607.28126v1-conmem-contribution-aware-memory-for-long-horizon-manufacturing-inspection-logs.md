## 摘要
长周期钢铁设备检验需要对多次检验周期中积累的异构记录进行推理。现有的检索增强生成系统将历史日志视为静态语料库，保留记录而不评估其诊断价值，无法报告早期风险。为此，我们提出ConMem，一种用于LLM辅助设备检验的贡献感知记忆框架，支持人在回路的早期风险筛查系统。具体而言，我们的ConMem首先将检验日志分割为功能性证据单元，然后通过Shapley风格估计评估每个记忆单元对下游诊断的贡献，最后在受限记忆预算下保留高价值证据。在实验中，我们在真实数据集上评估ConMem，其QA准确率达到76.0%，超过最强的直接可比基线。相对于朴素的8K上下文LLM基线，它减少了88.2%的平均输入token数和86.6%的响应时间。消融研究还表明，功能性角色感知分割和基于贡献的评估有助于优先处理弱退化信号，以进行有针对性的现场检验。实际部署进一步证实，ConMem在三个检验周期中保留了弱早期信号，为现场检查人员提供了针对性的早期密封磨损警报。

## Abstract
Long-horizon steel-equipment inspection requires reasoning over heterogeneous records accumulated across repeated inspection cycles. Existing retrieval-augmented generation systems treat historical logs as a static corpus and retain records without estimating their diagnostic value, failing to report early risk. To this end, we propose ConMem, a contribution-aware memory framework for LLM-assisted equipment inspection, supporting a human-in-the-loop early-risk screening system. Specifically, our ConMem first segments inspection logs into functional evidence units, then estimates each memory unit's contribution to downstream diagnosis through a Shapley-style estimation, and finally retains high-value evidence under a constrained memory budget. In experiments, we evaluate ConMem on real-world dataset and ConMem achieves 76.0% QA accuracy, exceeding the strongest directly comparable baseline. Relative to the naive 8K-context LLM baselines, it reduces the average number of input tokens by 88.2% and response time by 86.6%. Ablation studies also show that the functional-role-aware segmentation and contribution-based valuation are helping prioritize weak degradation signals for targeted field inspection. Practical deployments further confirm that ConMem retains the weak early signal across three inspection cycles, providing an early-stage seal-wear alert targeted for on-site inspectors.

## 2. 方法论：ConMem 框架

### 核心思想

ConMem 是一个三阶段的贡献感知记忆管理框架，核心思路是：**并非所有巡检记忆对诊断同等重要，应该按贡献而非相似度来保留和检索证据**。系统建立在"边际效用递减"这一经验观察之上——当检索到最有价值的3个证据段后，继续增加记录带来的准确率提升几乎可以忽略。

### 关键技术细节

**阶段一：功能角色感知分割（Functional-Role-Aware Segmentation）**
- 针对通用记忆系统仅按文本连续性切分的缺陷，利用巡检日志天然存在的功能角色转换（设备状态→安全隐患→维护动作）进行切分。
- 具体流程：先用NLP管道提取名词短语（概念库），训练轻量编码器 E_light 将概念映射到冻结的SBERT空间；然后在滑动窗口内计算概念相似度，当 sim_t < τ 时判定为角色边界。
- 引入领域自适应阈值：τ_c = τ₀ · exp(−w_c/Σwⱼ)，关键部件（如输送带）获得更高保真度切分。

**阶段二：Shapley式贡献估计（Contribution Estimation）**
- 对每个分割得到的证据单元 sᵢ，计算Shapley值衡量其对下游诊断的边际贡献：

  φᵢ = Σ_{T⊆S\{sᵢ}} [U(M_T∪{sᵢ}) − U(M_T)] / [m · C(m−1, |T|)]

- 效用函数 U(M) = α·Acc + β·Rel + γ·Tim，其中Acc是事实准确率、Rel是与设备部件的相关性、Tim惩罚过时信息；系数α=0.45, β=0.45, γ=0.1。U只用时间上更早的训练数据估计，测试期间保持不变。
- 基于边际效用递减（∂U/∂|T| ∝ e^(−λ|T|)），采用重要性剪枝分层采样：只评估规模 ≥ n−2 的组合，将2ⁿ次LLM调用降至O(n²)次（n≈20时，从指数级降到约211次评估），近似精度保持1%以内。

**阶段三：优先级存储与检索（Priority-Based Storage & Retrieval）**
- 按Shapley值将证据段存入最大堆，容量受限时优先驱逐低贡献段。
- 自适应驱逐阈值 θ = percentile({φ̂ᵢ}, p)，p为目标保留百分位（实验中最优为25%）。
- 查询时先从高Shapley候选集合中语义检索Top-K证据段，再交给LLM生成答案。

**整体复杂度**：T_total = O(n·d) + O(ρ·τ) + O(K log m)，单次查询从Naive Context的18.76秒降至约2.5秒。

## 6. 主要结论与发现

1. **ConMem在真实钢铁巡检数据上达到76.0%的QA准确率**，超过最强的直接可比基线Mem0（74.7%）；相比Naive Context-8K减少88.2%的输入token、86.6%的响应时间。
2. **贡献感知优于启发式策略**：Random Memory在25%预算下仅50.0%，Rule-based Memory为52.0%，而ConMem同预算下达76.0%——差距显著。
3. **功能角色感知分割至关重要**：移除该模块后准确率从76.0%骤降至32.0%，是所有消融中影响最大的。
4. **Shapley式估值有效捕捉边际效用递减现象**：移除后准确率降至52.0%；验证了"少而精"的记忆保留策略（最佳为25%预算）。
5. **骨干模型无关性**：ConMem在GPT-4o和GLM-4骨干下均保持76%准确率，而Mem0在GLM-4下骤降至45.9%，证明ConMem的记忆管理机制不依赖大模型自身的隐性记忆能力。
6. **部署验证**：15天现场试验中，ConMem召回率78.7%（TP=295，FN=80），远高于阈值法（52.5%）和Raw-log RAG（57.6%）；平均提前12天预警，显著提升异常发现的时敏性。
7. **理论保证**：高阶层截断（k* ≥ n−2）的近似误差有界：|φᵢ − φ̂ᵢ| ≤ (n−2)/n · ε，在n≤20时将评估次数从指数级降为O(n²)。

## 7. 方法优点

- **领域适配深入**：不是简单套用通用记忆系统，而是针对巡检日志的功能角色异构性设计分割方法；关键部件（如输送带）获得更高保真度，体现出领域知识的注入。
- **理论支撑扎实**：利用Shapley值（合作博弈论）给出贡献度量的公理化基础，并配套了近似误差上界的理论证明；边际效用递减假设不仅有经验支撑，还被定理量化。

- **跨骨干鲁棒性**：通过双LLM实验排除了"方法强只是因为骨干强"的混淆因素。

## 8. 不足与局限

- **数据覆盖单一**：仅使用一个钢铁企业的数据集，缺乏跨行业、跨设备类型的验证。分季节实验样本不均衡（冬季N=37 vs 夏季N=18），结论的季节泛化性存疑。
- **Shapley估值的训练集依赖**：效用函数U的系数（α, β, γ）和λ衰减率是从训练数据中估计的，一旦新场景的查询分布或异常类型发生变化，贡献评估可能产生域偏移。
- **近似算法的经验假设**：k* ≥ n−2 的截断策略依赖"贡献排序在高阶组合中稳定"这一经验观察（表2），理论分析（附录）需要Assumption 2、3支撑，若场景中边际效用并非快速递减，近似误差可能显著增大。
- **LLM评估的固有成本**：虽然每个查询的推理已加速至约2.5秒，但Shapley估值阶段本质上需要O(n²)次LLM效用评估（离线进行），对于大型设备群（同时有数百台设备需要估值）的冷启动成本未做分析。
- **部署规模有限**：15天、1,125次任务仅涉及单一合作伙伴工厂；136次未确认警报（FP）说明误报率仍偏高（精确率68.4%），论文对此仅以"更适合作决策支持而非替代人工"带过，未分析误报的具体模式。
- **反直觉结果未解释**：Full Event Retrieval（全量历史事件）准确率（72.0%）低于ConMem（76.0%），暗示信息过载会损害LLM推理，但论文没有从上下文长度、注意力分散等角度做机制分析。
- **可复现性细节不足**：开源代码链接为匿名页面，但具体的数据预处理流程、查询模板构造方式、人工标注一致性（ICC评分）等细节未完整披露，影响复现可信度。
