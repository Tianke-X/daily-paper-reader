## 摘要
近期推理时扩展的进展显著释放了大型语言模型（LLMs）的复杂推理能力。然而，对于智能体而言，这些方法存在关键的低效问题：以无状态方式运行，并参与冗余的搜索过程。现有记忆机制主要依赖LLMs的推理能力，导致计算成本过高。在本文中，我们提出一种新框架，名为GAMER（基于图的动作中心记忆与情景推理），弥合推理扩展与情景记忆之间的鸿沟。我们的方法将历史推理建模为动态的“动作中心图”。通过将记忆机制与LLMs解耦，我们的方法相比记忆机制基线，能够提供更少的记忆上下文，从而节省token/资金消耗。为有效从图中提取知识，我们使用双流时间差分学习机制，基于过往成功与失败估计动作节点的正向（建议）与负向（规避）价值。在推理阶段，学习到的价值函数双向优化决策，使正向价值提供动作建议，而负向价值指示高风险动作。通过在图上进行高效搜索，我们的方法显著提升了推理扩展的效率。在多个基准上的实验表明，与原始基线相比，GAMER在成功率/进度率上实现了20.81%/6.17%的显著提升。

## Abstract
Recent advancements in inference-time scaling have significantly unlocked the complex reasoning capabilities of Large Language Models~(LLMs). However, for agents, these approaches suffer from a critical inefficiency, operating in a stateless manner and engaging in redundant search processes. Existing memory mechanisms largely rely on the reasoning capabilities of LLMs, leading to prohibitive computational costs. In this paper, we propose a novel framework, \textit{GAMER}~(Graph-based Action-centric Memory with Episodic Reasoning), that bridges the gap between inference scaling and episodic memory. Our approach models historical reasoning as a dynamic \textit{Action-Centric Graph}. By decoupling the memory mechanism from LLMs, our method can save token/money usage by providing less memory context than memory mechanism baselines. To extract knowledge from the graph effectively, we use a dual-stream Temporal Difference learning mechanism to estimate the positive~(suggestion) and negative~(avoidance) value of action nodes based on past successes and failures. During the inference phase, this learned value function optimizes decision-making bi-directionally, so that positive values provide action suggestions, while negative values indicate high-risk actions. By performing efficient searches on the graph, our method significantly improves the efficiency of inference scaling. Experiments on multiple benchmarks demonstrate that \textit{GAMER} achieves superior performance by \textbf{20.81\%/6.17\%} for success/progress rate compared to vanilla baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：推理时扩展（Inference-time Scaling）技术（如 CoT、ToT）显著增强了 LLM 的复杂推理能力，但在智能体（Agent）场景下存在根本性缺陷——这些方法以"无状态"（stateless）方式运行，每次面对任务都从零开始搜索，无法利用过往经验，导致大量冗余搜索和巨额 token 消耗。
- **现有记忆机制的不足**：已有记忆方法（如 AWM、ReasoningBank、A-MEM、G-MEM 等）存在两类问题：
  - 高度依赖 LLM 自身的推理能力来提炼知识，计算成本高昂；
  - 本质上只是"上下文增强/检索模块"，注入事实性信息，既不剪枝搜索空间，也不指导决策过程，无法解决冗余推理的 dominant cost。
- **核心矛盾**：如何在保持推理时扩展能力的同时，让智能体拥有可复用、低成本的情景记忆（Episodic Memory），实现"越用越快、越用越准"。
- **论文定位**：提出 GAMER（Graph-based Action-centric Memory with Episodic Reasoning）框架，将记忆机制与 LLM 推理过程解耦，通过动作中心图（Action-Centric Graph）+ 价值学习，弥合推理时扩展与情景记忆之间的鸿沟。

## 2. 方法论

### 2.1 核心思想
- 将历史轨迹（trajectories）抽象为**动作中心图** G=(V, E)：节点表示不同动作（action），有向边表示动作间的时序依赖关系。
- 与传统"存储原始文本"的记忆系统不同，GAMER 将记忆从被动的日志存储转变为主动的决策图结构。
- 关键洞察：虽然任务描述千变万化，但底层推理步骤在不同任务间往往具有结构相似性。

### 2.2 关键技术细节（三阶段流程）

**阶段一：图构建（Graph Construction）**
- 输入历史轨迹池 D = {τ₁, τ₂, ..., τₙ}，每条轨迹由（观察、动作、奖励）序列组成。
- 节点 = 去重后的唯一动作；边 = 历史中观察到的动作相邻转移关系（aⱼ 紧跟 aᵢ 执行）。
- 分支点代表决策状态，环代表递归推理循环。

**阶段二：双流时序差分学习（Dual-Stream TD Learning）**
- 使用 TD 学习（而非等最终结果）估计动作节点的长期价值，更新规则：
  - δₜ = rₜ + γ·E[Q(vₜ₊₁)] − Q(vₜ)
  - Q(vₜ) ← Q(vₜ) + α·δₜ
- **双流机制**（解决单值函数中和风险信息的问题）：
  - **正向价值 Q⁺(v)**：用标准环境奖励 rₜ 更新，估计动作的期望成功率；
  - **负向价值 Q⁻(v)**：引入阈值化奖励重定义 rₜ⁻ = −1（若 rₜ < εᵣ），否则 0，专门追踪历史上导致次阈值表现/失败的高风险动作。
  - 示例说明：某动作 50% 得 +1、50% 得 −1，期望值为 0，与平庸动作无法区分；双流机制将这种"高风险"信号保留下来。
- 更新目标：Q⁺ 用 max 后继值，Q⁻ 用 min 后继值，分别独立更新。

**阶段三：记忆引导的推理扩展（Memory-Guided Inference Scaling）**
- **参考轨迹引导**：检索历史最优轨迹 τ\* 作为 few-shot 示例，提供整体规划蓝图。
- **双流动作注入**：
  - 建议动作（Suggested Actions）：当前节点后继中 Top-K 高 Q⁺ 值动作；
  - 规避动作（Actions to Avoid）：Top-K 低 Q⁻ 值动作（历史已知陷阱/死胡同）。
- **提示集成**：将三类信号（τ\*、建议、警告）动态注入 LLM prompt，通过上下文学习引导概率分布偏向高价值区域、抑制高风险路径，不修改底层解码过程。

### 2.3 理论分析

## 7. 优点

- **概念创新**：将记忆系统从"被动存储/检索"范式转变为"主动决策图 + 价值函数"范式，从计算优化而非上下文增强的视角解决问题，定位清晰。
- **解耦设计**：记忆构建与价值学习不依赖 LLM 推理能力，成本可控、token 消耗可预测，与强依赖 LLM 摘要能力的 A-Mem/ReasoningBank 形成鲜明对比。
- **双向学习**：同时从成功和失败轨迹中学习（正向建议 + 负向规避），避免单值函数中和风险信息的问题，设计巧妙且具有理论支撑（FSD 证明）。
- **轻量高效**：图构建秒级、TD 学习亚秒级，推理时间显著优于 A-Mem；实验严格隔离 GPU 环境，保证可复现性。
- **实验扎实**：4 benchmark × 4 LLM × 多类基线 + scaling 曲线 + token/时间分析 + 完整消融，覆盖面在同类工作中属于较全面水平。

## 8. 不足与局限

- **对 warm-up 数据的依赖**：论文明确承认，当 warm-up 轨迹过少（如 4–8 条）时性能明显下降（AlfWorld 上 SR 从 49.25% 降至 42.92%），甚至可能低于 vanilla 基线；初始知识不足时可能收敛到次优行为模式。
- **极端性能不一致**：在 PDDL 和 Tool 上，GAMER 与 vanilla 的差距相对较小（PDDL SR 7.08% vs 5.83%），且部分设置下（如 Llama-Tool）提升有限甚至不敌 vanilla（Llama 上 Vanilla 33.33%、GAMER 28.33%），说明在特定任务-模型组合下优势并不稳定。
- **实验充分性缺口**：消融实验未覆盖全部组合；缺少统计显著性检验和多次运行的方差报告；GPT 上的总体 SR 表现弱于 A-Mem 的现象未获充分解释。
- **理论假设较强**：FSD 证明依赖"价值估计 ε-一致"与"概率重分配单调性"等假设，实际中 Q 值估计误差和 LLM 上下文遵循度可能偏离假设。
- **应用限制**：动作空间需有可比较的文本表征，对连续动作/低层控制场景的适用性未验证；图结构依赖动作序列的可离散化，对开放式长尾任务可能失效。
