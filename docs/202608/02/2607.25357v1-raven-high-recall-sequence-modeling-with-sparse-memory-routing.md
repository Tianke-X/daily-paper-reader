## 摘要
线性时间序列模型中的长上下文召回凸显了它们在写入记忆时的一种权衡。基于状态的线性模型，如状态空间模型（SSM）和线性Transformer，进行密集写入，即为每个新到达的token更新整个状态，这会导致干扰并使特定的过去token难以恢复。滑动窗口注意力（SWA）则表现出相反的行为：它通过存储显式的token表示来进行稀疏写入，但仅限于固定窗口内，因此一旦相关token被驱逐，召回率就会下降。在这两类模型之间进行插值，我们引入了Raven，这是一种线性时间序列模型，它维护一组固定的记忆槽，并在每一步通过学习的、依赖输入的路由仅对选定的子集进行衰减和更新。这使得Raven能够缓解SWA基于位置的覆盖和硬性驱逐，同时减少SSM中密集状态更新带来的干扰，从而更有效地保留长距离内容。在召回密集的基准测试中，Raven与先前的线性时间基线相比具有竞争力或更优，在SWA和SSM都急剧下降的场景中实现了强大的长上下文召回。当外推到其训练长度16倍的上下文长度时，它仍然保持有效，并且在混合架构中也有类似的收益。

## Abstract
Long-context recall in linear-time sequence models highlights a tradeoff in how they write to memory. State-based linear models, such as state-space models (SSMs) and linear Transformers, write densely, updating the entire state for each newly arrived token, which leads to interference and makes specific past tokens hard to recover. Sliding-window attention (SWA) exhibits the opposite behavior: it writes sparsely by storing explicit token representations, but only within a fixed window, so recall drops once the relevant token is evicted. Interpolating between these models, we introduce Raven, a linear-time sequence model that maintains a fixed set of memory slots and, at each step, decays and updates only a selected subset via learned, input-dependent routing. This lets Raven mitigate SWA's position-based overwriting and hard eviction while reducing interference from dense state updates in SSMs, thereby preserving long-range content much more effectively. Across recall-intensive benchmarks, Raven is competitive with or outperforms prior linear-time baselines, achieving strong long-context recall where both SWA and SSMs sharply degrade. It remains effective when extrapolating to context lengths as large as 16x its training length, with similar gains in hybrid architectures.

## 1. 论文的核心问题与整体含义（研究动机和背景）

论文聚焦于**线性时间序列模型在长上下文召回（long-context recall）任务中的根本性缺陷**，其核心观察可以概括为"记忆写入方式"的权衡：

- **状态空间模型（SSMs）与线性 Transformer**：采用**密集写入（dense write）**策略，每到达一个新 token 就更新整个隐藏状态（即所有记忆槽）。虽然理论上可以无限期携带信息，但密集更新导致**记忆槽之间的严重干扰（interference）**，使特定历史 token 难以被精确恢复。
- **滑动窗口注意力（SWA）**：采用**稀疏写入（sparse write）**策略，显式存储 token 表示但仅限固定窗口内。一旦相关 token 被驱逐出窗口，召回率骤降，且驱逐策略是基于位置的（FIFO），与内容无关。

论文的核心论点在于：**"信息写到哪里"与"信息能保留多久"是两个应当被解耦的设计维度**，而现有架构（SSM、SWA、GSA、ABC 等）都隐含地纠缠了这两个维度。这一洞察通过作者提出的**Routing Slot Memories（RSM）**框架被形式化，并揭示了现有模型谱系中缺失的一环——**稀疏、输入依赖的路由 + 显式衰减**。

Raven 正是填补这一空白的具体模型，它使得固定大小记忆模型在长上下文召回上接近甚至超越 Transformer，同时保持线性时间推理复杂度。

## 2. 论文提出的方法论

### 2.1 核心思想：Routing Slot Memories（RSM）框架

RSM 是一个统一的 slot-separable 线性循环框架，其一般形式为：

\[
S_t = (1 - r_t) \odot S_{t-1} + r_t \odot (D_t S_{t-1} A_t + U_t)
\]

其中：
- \( r_t \in \mathbb{R}^M \) 为**路由向量**，决定每个记忆槽的写入强度；
- \( D_t \) 为对角矩阵，保证槽间独立性（slot separability）；
- \( A_t \) 为特征维度的衰减矩阵；
- \( U_t \) 为写入内容。

在该框架下，现有模型可被理解为路由轴上的不同端点：
- **SSM/GLA/Mamba-2**：\( r_t = \mathbf{1}_M \)（密集路由，所有槽每步更新）；
- **SWA**：\( r_t = e_t \)（one-hot 时间依赖路由，硬驱逐）；
- **GSA/ABC**：输入依赖但**密集**路由；
- **Raven**：**稀疏 + 输入依赖 + 显式衰减**。

### 2.2 Raven 的具体设计

**记忆更新公式**（双状态：键记忆与值记忆）：

\[
S^k_t = \exp(a_t r_t) \odot S^k_{t-1} + (1 - \exp(a_t r_t)) k_t^\top
\]
\[
S^v_t = \exp(a_t r_t) \odot S^v_{t-1} + (1 - \exp(a_t r_t)) v_t^\top
\]
\[
o_t = (S^v_t)^\top \text{softmax}(S^k_t q_t)
\]

关键特性：
- **稀疏路由**：当 \( r_t[i] \approx 0 \) 时，槽 i 完全不更新（冻结），内容精确持久化；
- **衰减**：标量 \( a_t < 0 \) 采用 Mamba-2 风格的输入依赖对数尺度衰减（SoftPlus），仅作用于被选中的槽；
- **路由机制**：借鉴 DeepSeek MoE 的 Top-K 策略——先通过 sigmoid 计算各槽分数，保留 Top-K 后归一化；使用 Gumbel 噪声防止训练中路由崩溃。

**块设计**：Raven 使用 Gated MLP 作为通道混合器 + SiLU 激活 + QK-RMSNorm，**完全省略了短卷积层**，比 Mamba/GDN 等现有线性模型更简洁。

## 6. 论文的主要结论与发现

1. **Raven 实现了优越的长上下文召回**：在 NIAH-1 上，400M 模型在 32K（16× 训练长度）仍保持 >91% 准确率，而 Mamba-2/GDN 等最强线性基线已降至 ~20%；800M 模型在 64K 保持 91% 准确率，远超 GDN（45.2%）和 FoX（0%）。
2. **稀疏输入依赖路由是长上下文召回的钥匙**：Raven 在每个训练步骤中都隐式地让不同记忆槽经历不同有效序列长度（非均匀 ESL），从而天然实现长度泛化，无需显式的状态传递或长度课程。
3. **真实世界召回任务同样受益**：SWDE 上 Raven 达到 34.1%（400M），超越所有线性基线；FDA 上突破 22%，较最佳 SSM 基线提升约 8 个点。
4. **通用语言建模不受损**：Raven 在 400M 规模下平均准确率与 Mamba-2/GLA 相当甚至更优，在 Lambada 上取得所有模型最佳困惑度。
5. **混合架构增益显著**：Raven+NoPE 注意力的混合模型在 NIAH-2/3 长上下文上大幅超越 GDN/Mamba-2 混合变体，在 32K 上保持 80%+ 准确率。
6. **记忆分配是结构化的**：可视化分析显示，Raven 自发形成"检索槽"（专存 passkey）、"共享槽"和"通用槽"三类分工，且不同层、不同头的分工模式各异，这验证了内容感知路由的有效性。
7. **设计简化有效**：无需短卷积即可达到最优召回，证明路由+局部衰减足以解决召回瓶颈。

## 7. 优点

### 方法创新性
- **理论视角清晰**：RSM 框架将分散的模型族（SSM、SWA、GSA、ABC、DeltaNet）统一到"路由 × 衰减"两个正交轴上，揭示了此前未被系统化的设计缺口；
- **动机与方案对应精准**：密集写入→干扰、固定窗口→硬驱逐，Raven 的选择性写入恰好同时缓解两个问题，逻辑链条完整；
- **模型简洁**：在 400M/800M 规模无需卷积和额外技巧即可达到 SOTA 召回，结构比 Mamba-2/GDN 更简单；
- **长度泛化机制新颖**：非均匀 ESL 的引入为线性模型的长度泛化提供了全新解释——训练中天然覆盖不同"有效长度"的分布。

### 实验设计亮点
- **记忆预算精确匹配**：首次在召回任务对比中高度关注循环状态的实际元素数对齐，降低不公平对比风险；
- **消融全面且有体系**：从架构组件到路由设计再到记忆形状，层次清晰；
- **分析实验质量高**：通过有效序列长度（ESL）概念和记忆槽可视化，直接验证了机制的真实运作方式，而不仅是性能指标的堆砌；
- **混合架构的多维度对比**：同时对比了注意力类型（NoPE/RoPE/SWA）与线性组件（GDN/Mamba-2/SWA-RoPE/Raven）的交叉组合。
