## 摘要
长时程自我中心记忆将连续的第一人称视频和音频转换为可搜索的过往经历记录。我们发现现有系统存在两个瓶颈：由缺乏上下文的标题构建的索引在智能体搜索中不可靠，而检索忽略了问题的时间意图。为解决这两个瓶颈，我们提出了EgoCITE（自我中心上下文增强索引与时间感知证据检索），一种用于自我中心问答的长时程智能体记忆框架。EgoCITE包含三个组成部分。EgoScheme利用局部多模态上下文将碎片化的视频标题和语音转录转换为自包含的原子记忆索引。EgoIndex将互补的动作、活动、话语和对话表示组织为多粒度、可搜索的多视角记忆索引。EgoRetrv结合语义搜索与基于问题条件的时间相关性评分及检索证据的策展。我们在EgoLifeQA、EgoMem和EgoR1-Bench上评估了EgoCITE的答案准确性和目标事件检索对齐度。EgoCITE相比智能体记忆基线将准确性提升了至少4.4%至14.2%，同时比长上下文LLM智能体降低了36倍的成本。

## Abstract
Long-horizon egocentric memory transforms continuous first-person video and audio into a searchable record of past experiences. We demonstrate two bottlenecks in existing systems: indices built from context-poor captions are unreliable for agentic search, while retrieval ignores a question's temporal intent. To address both bottlenecks, we introduce EgoCITE (Egocentric Context-augmented Indexing and Time-aware Evidence retrieval), a long-horizon agentic memory framework for egocentric QA. EgoCITE comprises three components. EgoScheme uses local multimodal context to turn fragmentary video captions and speech transcripts into self-contained atomic memory indices. EgoIndex organizes complementary action, activity, utterance, and conversation representations into searchable multi-view memory indices at multiple granularities. EgoRetrv combines semantic search with question-conditioned temporal relevance scoring and curation of retrieved evidence. We evaluate EgoCITE on EgoLifeQA, EgoMem, and EgoR1-Bench in terms of answer accuracy and target-event retrieval alignment. EgoCITE improves accuracy over agentic memory baselines by at least 4.4--14.2% while achieving 36$\times$ lower cost than long-context LLM agents.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：长时程自我中心记忆（Long-Horizon Egocentric Memory）旨在将可穿戴设备持续捕获的第一人称视频和音频转化为可搜索的日常经历记录，从而支撑记忆增强、AR 眼镜、生活助手等新兴应用。然而，现有系统的可靠性受制于两个根本性瓶颈：
  - **索引语义贫乏（Construction Bottleneck）**：现有系统直接从短时、独立生成的视频字幕和语音转写构建记忆索引。这些索引常缺少必要的局部上下文——人物身份、对象指代、省略表达等未被解析，导致“内容从未被表示，后续检索也无从重建”。
  - **检索忽视时间意图（Retrieval Bottleneck）**：检索仅依赖语义相似度排序，把时间当被动元数据。但自我中心记忆的问题常含“last”“first”“usually”“this morning”等时间限定，语义最相似的事件未必是问题所问的那一次，导致检索失败。
- **论文含义与定位**：提出 EgoCITE 框架，主张“索引自包含 + 检索时间感知”是长时程自我中心记忆可靠性的前提。不同于以往单纯增加记忆结构复杂度（知识图谱、多尺度层级）的思路，该工作强调在**构建期**利用局部上下文生成自包含原子索引，在**检索期**显式建模时间意图，将二者解耦并各司其职。

## 2. 论文提出的方法论

- **总体架构**：EgoCITE 是一个四阶段流水线：
  1. 多模态感知与字幕生成（视频视觉字幕+语音转录→融合为多模态字幕）；
  2. **上下文增强的原子记忆索引构建（核心贡献之一）**；
  3. **时间感知的原子记忆索引检索（核心贡献之二）**；
  4. 推理与作答（检索证据送回字幕，LLM 按选择题作答）。
- **EgoScheme（上下文增强原子索引构建）**：
  - 利用每个当前字幕前 T 分钟（默认 5 分钟）的相邻字幕作为上下文窗口，让 LLM 解析共指（coreference）和省略（ellipsis），生成**自包含**的原子记忆索引。
  - 定义四类视图的明确规范：
    - **Action**（动作）：细粒度物理行为，分 Hand-Object Interaction、Gesture、Movement 三类，要求命名人物、具体对象和可达目的地；
    - **Utterance**（话语）：细粒度言语行为，要求命名说话者，并用 WHAT/THAT 从句给出完整命题内容（如“Jake confirms that all the packages are outside”）；
    - **Activity**（活动）：粗粒度目标导向行为，要求包含具体目标、参与者、对象和地点；
    - **Conversation**（对话）：粗粒度话题交流，要求列出所有参与者并保持单一连贯话题。
  - 对相邻窗口中的连续活动/对话，用句向量相似度识别连续片段并 LLM 合并；对“and/while”连接的复合内容做解耦拆分，确保单一索引只描述单一行为。
- **EgoIndex（多视图多粒度记忆索引）**：
  - 将经验沿两个轴组织：物理行为 vs 语言交互；细粒度 vs 粗粒度语义，形成四种互补记忆视图：action / activity / utterance / conversation。
  - 每个原子索引携带时间戳；所有索引通过 Qwen3-Embedding-4B 嵌入、FAISS 建库。
- **EgoRetrv（时间感知检索）**——双智能体设计：
  - **起草智能体（Drafting Agent）**：多轮迭代检索，每轮生成结构化查询集合 Q = {Qs（语义查询）, Qv（视图指定）, Qt（可选时间查询）}，可调用 search_action_utterance / search_activity / search_conversation 等工具，将结果累积到**索引池（Index Pool）**中；也可调用 curate_index 清理池子。
  - **采样/策展智能体（Sampling Agent）**：读取索引池后，根据问题中的时间限定词（“usually”→选择跨时间多样化集合；“last”→优先最新时间戳；“first”→最早时间戳）显式策展最终证据集，控制返回给答案智能体的证据在 5–15 条之间。
  - **时间相关性评分**（核心公式）：
    - 时间查询 Qt = [tstart, tend]（点估计则 tstart = tend）；
    - 将时间戳映射到统一连续时间轴（小时为单位）后，计算时间相关性：R_i = 1（在窗口内）；λ^(tstart−τi)（早于窗口）；λ^(τi−tend)（晚于窗口），其中 λ 为时间衰减因子（默认 0.99，经消融实验确定）；
    - 综合检索分数 = 语义相似度 S_i × 时间相关性 R_i，即 score(mi|Qs, Qv, Qt) = S_i · R_i；
    - 软衰减设计避免硬截断的脆弱性，对模糊时间表达（如“at noon”）具备容忍度。
- **设计要点总结**：
  - 构建期：局部上下文 → 自包含原子索引；
  - 检索期：时间相关性在嵌入空间之外显式建模，避免句向量对时间不敏感的问题；
  - 双智能体解耦：“高召回收集”与“高精度策展”分离。

## 6. 论文的主要结论与发现

- **EgoCITE-GPT 在所有三个基准上为最强配置**：比长上下文 LLM 智能体高 3.6–8.9%（EgoLifeQA）、0.9–4.1%（EgoMem）、2.6–4.7%（EgoR1-Bench）；比最强智能体记忆基线平均提升至少 14.2%、4.4%、9.0%。
- **成本优势显著**：5 轮默认配置比 GPT-5.4 agent 输入 token 少 24.7×、归一化成本低 36×、延迟相近（32.0s vs 32.5s）；比 WorldMM-GPT 输入 token 少 2.3×、成本低 2×、延迟低 14.8s 且准确率更高。
- **时间感知检索有效**：在时间感知问题子集上，EgoCITE-GPT 达 62.6%（比最强基线 Gemini-3.1-Pro agent 高 3.9%，比 WorldMM-GPT 高 15.5%）；现有模型在时间感知问题上比时间非感知问题准确率低 9.8–13.3%，说明时间意图是不可忽略的检索信号。
- **组件各有贡献**：EgoIndex、EgoScheme、EgoRetrv 三个组件逐步将准确率从 61.3% 提升到 69.7%、71.3%、75.3%，Hit Rate 从 40.7% 提升至 54.3%、59.3%、62.7%。
- **记忆可扩展性好**：从 DAY1 到 DAY7，EgoCITE 准确率仅下降 4.8%，远优于 GPT-5.4 agent 的 11.9%，说明结构化多视图记忆+时间感知检索比超长上下文推理更能应对记忆规模增长。
- **对噪声字幕鲁棒**：用 VLM 生成的视频字幕替代人工标注密集字幕，准确率仅下降 1.2%（Gemini-3-Flash）和 4.4%（Gemma-4-31B），具备实际部署可行性。

## 7. 优点

- **问题诊断精准且有数据支撑**：附录中对 WorldMM 和 LoCoMo 的失败模式做了大规模量化分析（92,131 个三元组中 10.1% 含未解析代词，254,997 条观察中 17.4% 含逐字引语），让“索引语义贫乏”不是口号而是实证发现。
- **方法解耦清晰**：构建期做上下文增强、检索期做时间推理，职责分明；EgoScheme（索引质量）、EgoIndex（视图组织）、EgoRetrv（时间感知）三组件可独立验证、单独消融。
- **时间相关性设计巧妙**：软指数衰减（λ = 0.99）既把时间意图注入检索排序，又对模糊时间表达有容忍度；时间查询可由起草智能体跨轮迭代更新，形成渐进式时间信念修正。
- **双智能体检索-策展机制合理**：高召回收集与高精度筛选分离，策展智能体显式依据问题中的时间限定词（usually/last/first）做取舍，解决习惯类、多证据类问题对多时间点信息的需求。
- **效率与成本的系统化度量**：不是只报告准确率，而是综合准确率-延迟-成本三维做 Pareto 分析，清晰的 token 数和价格测算使读者能直接评估实用价值。
- **评测覆盖全面**：三个基准 + 时间子集 + 多轮消融 + 记忆扩展性 + 真实 VLM 字幕变体，多角度验证了方法的有效性和鲁棒性。

## 8. 不足与局限

- **感知能力仍是瓶颈**：论文假设人物身份是先验知识（视觉外观-声音-姓名映射）且 ASR 转录准确、说话人分离可靠；在现实隐私保护（脸被遮盖）、服装发型跨天变化、ASR 错误、重叠语音等情况下，记忆构建质量会显著下降。
- **跨模态信息利用不充分**：共指/省略解析是在文本化字幕上做的，丢失了视线、指向手势、说话人定位、物体交互等跨模态线索，论文自己在 Future Work 中也承认了这一点。
- **检索结构与记忆结构简单**：采用 FAISS 向量库作为唯一索引结构，未与知识图谱（如 WorldMM、EgoGraph）等更丰富结构结合；关系推理、层级组织等能力未被探索。
- **Hit/NearHit 与最终准确率之间存在缺口**：EgoCITE-GPT 在 EgoLifeQA 上 11.3% 的问题检索到目标证据却答错，12.6% 的问题未命中标注证据却答对——前者说明推理能力提升空间，后者说明基准证据标注可能存在噪声或非排他性。
- **时间感知子集构建存在主观性**：按关键词分类时间感知问题，76% 的比例可能高估了时间意图问题的实际占比；消融实验部分在小规模子集（如 λ 消融只在 100 题上）进行，统计稳健性有限。
- **成本测算是近似值**：归一化成本基于公开 API 定价，未包含 VLM 字幕生成、嵌入计算、向量检索等全链路成本；视频处理环节的实际开销未被整体核算。
- **应用限制**：当前方法以选择题 QA 为主要任务形式，对开放域问答、多轮对话式回忆等场景的适用性未

## 8. 不足与局限（续）

- **应用限制（续）**：得到验证；选择题格式本身带有选项线索，可能在一定程度上掩盖了检索-推理的薄弱环节——模型即使未命中目标证据，也可能因选项间的区分度较低而“猜对”。对于开放式问答、自由回忆、多轮对话式记忆唤醒等更贴近实际生活助手的使用场景，当前框架的泛化能力尚未得到检验。
- **时间推理粒度仍显粗糙**：EgoRetrv 的时间建模是“索引级”的（时间戳精确到 30 秒窗口），但问题中的相对时间表达（如“after lunch”“before dinner”“when I was cooking”）需要的是事件间顺序关系而非绝对时间戳，现有机制对这类时序逻辑的处理仍依赖 LLM 的隐式推理，缺少显式的时间关系图或事件顺序编码。
- **索引构建的单次性**：EgoScheme 在每个 5 分钟上下文窗口内做一次增强，但对跨窗口、跨天复用的人物身份、地点常量和长期目标缺乏累积性记忆；换言之，局部自包含解决了短程指代，却未解决长程知识（如“我经常去的健身房是哪家”）的持续维护问题。
- **评估基准仍非真实应用**：三个基准均基于 EgoLife 单一人群、单一场景（居家/自由生活）的数据采集，参与者规模和语义多样性有限；且所有问题由人工撰写而非真实用户查询，问题分布可能与实际使用中“我现在找不到钥匙了”“昨天那个视频里我提到的人是谁”这类诉求存在系统性偏差。

## 9. 总体评价与启示

- **一句话定位**：EgoCITE 不是一种“更大更强”的记忆系统，而是一种“更正确”的记忆系统——它把长期记忆失败的根因归结为构建期的语义贫乏和检索期的时间盲目，并分别用 EgoScheme 与 EgoRetrv 进行对症治疗，属于典型的“问题驱动、机制对症”式研究。
- **对本领域的范式启示**：论文用充分的失败案例分析（未解析代词、逐字引语、密集字幕中的低信息密度）证明：在长时程自我中心记忆中，**索引的语言质量**和**检索的时间建模**比记忆结构本身的复杂度更关键。这为后续研究提供了一个可复用的经验：与其不断叠加知识图谱、层级摘要、图遍历等结构复杂度，不如先确保每个原子索引本身是自包含、可分发的语义单元。
- **架构上的工程价值**：EgoCITE 将记忆系统的各环节解耦为可替换模块（感知、构建、索引、检索、推理），每个模块可独立调优；且本地嵌入 + 云端 LLM 的混合部署策略，使其在算力受限的穿戴设备场景中具备工程可行性。
- **对未来工作的合理预期**：沿着“多模态感知融合（视觉线索直接参与指代解析）→ 跨天人物/场景编码 → 时间关系图 → 开放域推理”的路径继续演进，EgoCITE 的框架有可能成为可穿戴记忆助手从原型走向实际部署的基座之一。但在此之前，感知层的鲁棒性和时间推理的表达力仍是两道必须跨过的门槛。

**总体而言**，这是一篇问题诊断扎实、方法设计解耦、实验验证体系化的工作；其核心贡献不在于某一项技术指标的刷新，而在于对“记忆系统为何失败”这一问题的归因重构——用自包含索引解决表示问题，用时间感知检索解决对齐问题。这一思想对视频理解、智能体记忆、检索增强生成等领域均有启发意义，其局限也恰恰指明了后续研究最有价值的方向。
