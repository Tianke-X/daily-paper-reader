## 摘要
检索增强生成（RAG）通过将生成过程锚定于外部证据来提升大型语言模型，但也引入了来源信任问题：检索到的上下文可能是有用的、无关的，甚至具有误导性。现有的RAG系统通常对检索到的证据采用固定的信任策略，这可能导致过度信任不正确的上下文，或者在用户明确要求遵循上下文的行为时未能充分利用上下文。因此，我们提出了意图引导解码（IGD），这是一个根据用户意图在检索上下文与参数记忆之间进行仲裁的框架。IGD使用答案级过滤和词元级纠错来引导最终解码轨迹在检索上下文与参数记忆之间进行选择。我们在五个大型语言模型上对三个忠实问答基准和三个事实冲突基准评估了IGD，IGD显著提升了事实恢复能力，在事实冲突基准上相对于直接RAG取得了高达65.4个百分点的提升，同时保持或改善了严格的上下文遵循行为，这一发现凸显了在RAG中平衡事实性和忠实性的重要性。

## Abstract
Retrieval-augmented generation (RAG) improves large language models by grounding generation in external evidence, but it also introduces a source trust problem: retrieved context may be useful, irrelevant, or even misleading. Existing RAG systems often apply a fixed trust policy toward retrieved evidence, which can either over-trust incorrect context or underuse context when the user explicitly asks for context-following behavior. Therefore, we propose Intent-Guided Decoding (IGD), a framework that arbitrates between retrieved context and parametric memory according to user intent. IGD uses answer-level filtering and token-level correction to steer the final decoding trajectory between retrieved context and parametric memory. We evaluate IGD on three faithful QA benchmarks and three factual-conflict benchmarks across five LLMs, IGD substantially improves factual recovery, achieving gains of up to 65.4 percentage points on factual-conflict benchmarks over Direct RAG, while preserving or improving strict context-following behavior, this findings highlight the importance of balancing factuality and faithfulness in RAG.

## 1. 核心问题与整体含义

- **研究背景**：检索增强生成（RAG）通过引入外部证据增强 LLM 的知识密集型任务能力，但也引入了**来源信任问题**——检索到的上下文可能是有用的、无关的，甚至具有误导性（例如与稳定世界知识冲突、被对抗性篡改或来自不可靠来源）。
- **核心矛盾**：现有 RAG 系统对检索证据采用**固定信任策略**，导致：过度信任错误上下文（损害事实性）或无法在用户明确要求遵循上下文时充分利用证据（损害上下文忠实性）。这两者之间形成 **事实性（factuality）与忠实性（faithfulness）的权衡**。
- **论文主张**：实际 RAG 系统需要一个**意图感知机制（intent-aware mechanism）**，能在用户要求上下文遵循时跟随上下文，在用户要求事实稳健性时抵抗不可靠上下文，而非单一固定策略。

## 2. 方法论

论文提出 **IGD（Intent-Guided Decoding，意图引导解码）**，一个无需重新训练模型、直接作用于解码阶段的框架，在检索上下文与参数记忆之间进行**意图条件下的来源仲裁**。核心流程如下：

- **三条条件分支**：
  - **用户分支**：基于原始用户提示（问题+上下文+指令）的解码分布 p_user,t（即 Direct RAG 的分布）。
  - **上下文分支**：提示模型严格依据所选支持片段回答问题，得到 p_ctx,t；支持片段通过 IDF 加权的词汇定位器选取。
  - **记忆分支**：提示模型以闭卷方式（无上下文）回答，通过 M=3 个提示变体（基础闭卷提示、显式闭卷提示、尽力猜测提示）的集成得到 p_mem,t。
- **答案级记忆过滤器（Answer-Level Memory Filter）**：在解码前，对高置信度案例进行硬路由。通过长度归一化的候选答案对数似然计算记忆偏好（mM）和用户分支兼容性（mU），若记忆分支强烈偏好记忆答案（mM ≥ 3 倍）且用户分支不反对、记忆答案确与上下文答案不同且记忆一致性评分 ≥ 0.67，则直接将最终答案替换为记忆预览。
- **词元级校正（Token-Level Correction）**：对于未通过过滤器的案例，基于以下公式调整用户分支的词元分布：
  - p_final,t(v) ∝ p_user,t(v) × [p_ctx,t(v)/p_mem,t(v)]^{λ_t}
  - 其中 λ_t 控制干预方向（正值为偏好上下文、负值为偏好记忆）与强度。
- **λ_t 的确定分三步**：
  1. **激活门（Activation）**：用 Jensen-Shannon 散度（JSD，top-16 词元集计算）衡量上下文与记忆分支的分布冲突，经软门控函数（阈值 τ_low=0.10，τ_high=0.35，γ=2.0）决定是否干预。
  2. **置信度方向（Direction）**：结合指令模式先验（STRICT 模式 d=0.9，TRUTH 模式 d=0.3）与两分支的熵基置信度，计算上下文偏好得分，决定 λ_t 的方向。
  3. **可靠性缩放（Reliability Scaling）**：对正向干预用上下文片段支持度与质量的加权分数缩放；对负向干预用记忆预览的答案一致性分数缩放。
- **设计思想**：仅在分布冲突时局部、保守地调整，避免大范围改写生成轨迹。

## 3. 实验设计

- **数据集与基准（Benchmark）**：共 6 个 QA 基准，各含 500 样本：
  - **忠实组（faithful）**：KILT-NQ、TriviaQA、SQuAD——上下文支持标准答案，用于验证 IGD 是否保留检索收益。
  - **事实冲突组（factual-conflict）**：ConflictBank、NQ-Swap、CounterFact——上下文答案与世界知识答案冲突，用于验证是否能恢复事实答案。
- **提示模式（Prompt Modes）**：
  - **STRICT 模式**：明确要求严格依据上下文回答，事实冲突组按上下文准确率评估。
  - **TRUTH 模式**：明确要求将上下文视为可能有噪声，优先正确事实，事实冲突组按世界准确率评估。
- **对比方法**：Closed-book Q-only（无上下文诊断）、Direct RAG（同提示直接生成）、ExplicitSCR、RCR-InternalEval、RCR-ContextEval、RCR-InternalConf、MADAM-RAG。
- **评估指标**：归一化别名匹配的答案准确率，以及宏观平均的 **Intent-Aligned Score（IA）** 和 **参数恢复率（PRR）**。

## 5. 实验数量与充分性

- **主实验**：5 个 LLM（Qwen3-32B、Qwen2.5-14B、Llama-3-8B、Mistral-7B、Phi-4 14B）× 6 个基准 × 2 种提示模式，规模较大，且模型覆盖多家族、多尺度，具有较好的泛化性检验。
- **诊断实验**：闭卷 Q-only 评估各模型的参数记忆恢复上限，为 IGD 的事实恢复能力提供可解释的基线。
- **消融研究**：在 Qwen2.5-14B 上进行了 6 项核心组件消融（移除答案级过滤器、词元级校正、激活门、指令模式先验、可靠性缩放、记忆集成），比较 STRICT 与 TRUTH 模式的两个维度指标。
- **超参数敏感性**：分析了 λ_max 与 d_truth 对忠实与事实冲突表现的权衡，并展示"默认路由器"与 Direct RAG 的对比。
- **错误类型分析**：将事实冲突基准的输出归类为正确答案、误导上下文答案、未知/拒绝、其他答案，揭示 IGD 的行为变化。
- **片段定位器对比**：比较 IDF 定位器与 GPT-5 定位器在片段支持和下游 IGD 表现上的差异。
- **总体评价**：实验数量较充分，设计覆盖多层面（性能、消融、敏感性、错误分析、机制对比），**公平性较好**——IGD 与 Direct RAG 在相同提示下对比，隔离了解码阶段的作用；但对每个基准仅报告 500 个样本，部分数据集的稳定性有待验证。

## 6. 主要结论与发现

- **显式真相提示不足以抵抗误导上下文**：Direct RAG 在 TRUTH 模式下仍大幅受误导上下文影响，如在 Qwen2.5-14B 上，NQ-Swap 从闭卷的 91.5% 跌至 42.0%。
- **IGD 显著提升事实恢复能力**：在 TRUTH 模式下，IGD 对每项事实冲突基准均有提升，最大达 65.4 个百分点（Qwen3-32B 上的 CounterFact），同时忠实基准的准确率仅小幅下降；所有模型的 IA 分数均优于 Direct RAG（提升 9.6–23.0 个百分点）。
- **IGD 保留甚至提升严格上下文遵循**：在 STRICT 模式下，IGD 在多数模型上保持或提升事实冲突组的上下文准确率（例如 Qwen2.5-14B 在 NQ-Swap 上提升 18.0 个百分点），未出现"为追求事实性而牺牲忠实性"的副作用。
- **组件均有贡献**：词元级校正贡献最大（移除后事实世界准确率从 73.7 降至 52.8），答案级过滤器起高精度补充作用，激活门、模式先验、可靠性缩放和记忆集成共同防止过度干预并保持源稳定性。
- **参数记忆的可恢复性是关键上限**：PRR 分析显示 IGD 能恢复大部分可获得的参数信号，但恢复程度受闭卷能力限制。
- **片段支持与下游性能存在偏差**：用 GPT-5 定位器获得更好的片段支持准确率反而微降 IGD 性能，提示 IGD 需要的是对下游生成器和可靠性函数有用的片段，而非语义上最优的片段。

## 7. 优点

- **问题定位准确**：明确提出 RAG 中"事实性 vs. 忠实性"受用户意图条件约束，将固定信任策略问题转化为意图条件的来源仲裁问题。
- **方法设计巧妙**：通过三段分支 + 双层仲裁（答案级硬过滤 + 词元级软校正）实现精细控制，且只在发生分布冲突时才干预，保持局部性和保守性。
- **无需训练、即插即用**：不改变检索管线、不重训练模型，直接作用于解码阶段，实用性强。
- **通用性好**：在 5 个不同家族与规模的 LLM 上均有效，说明并非依赖单一模型的特殊行为。
- **实验设计客观**：使用相同提示对 Direct RAG 与 IGD，隔离了解码阶段变量；引入闭卷诊断、IA 指标和 PRR 指标全面评估行为模式。
- **分析深入**：不仅报告准确率，还通过错误类型分布、消融、超参数敏感性等揭示了 IGD 的内部机制和局限性，超越表面效果展示。

## 8. 不足与局限

- **依赖参数记忆可恢复性**：IGD 的事实恢复能力受模型闭卷知识上限约束，如果模型参数中没有正确答案（如长尾知识），IGD 无法凭空恢复事实。
- **超参数敏感且存在固有权衡**：λ_max 与 d_truth 等超参数需要调节；图 3 显示更强的记忆偏向会提高事实恢复但损害忠实基准，两者不可兼得。文中承认这是当前框架的核心局限。
- **残余不确定性**：错误分布分析显示，IGD 虽然大幅减少了误导上下文答案，但相当一部分错误流向"其他答案"类别——当记忆分支不稳定或证据冲突不干净时，无法可靠落到正确答案上。
- **上下文遵循的评估范围有限**：仅评估了短形式 QA，未覆盖长文本生成、对话或多步推理等更复杂场景。
- **外部基线在 STRICT 模式下未对比**：主要对比集中在 TRUTH 模式，STRICT 模式只对比了 Direct RAG，缺少与其他忠实性方法（如 Context-DPO、FaithfulRAG）的直接比较。
- **片段定位机制的矛盾未完全解决**：GPT-5 定位器与 IGD 性能不匹配的现象提示可靠性函数与下游生成器之间存在目标偏差，但论文未深入修正这一问题。

- **每个基准仅 500 样本**：规模较小，且未提供置信区间或多次运行稳定性分析，统计显著性未充分验证。
