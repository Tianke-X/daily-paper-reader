## 摘要
随着智能体任务复杂度的增长，LLM智能体日益依赖经验记忆来跨任务复用程序性知识。有效的记忆设计必须同时解决存储什么、记忆如何结构化与检索，以及记忆如何进化的问题。现有系统仅部分解决这些问题：它们将轨迹、洞察或工作流作为孤立条目存储，丢弃了子任务与可复用技能之间的组合关系；通过忽略关系信号的扁平嵌入相似性进行检索；且在维护记忆时未利用其关系结构。我们提出HyperSkill，一种基于超图的记忆框架，同时改进上述三个方面。HyperSkill将记忆表示为具有两种节点类型的超图，即子任务步骤和可复用技能，其中每条超边连接来自单条轨迹的子任务和技能。双路径检索同时查询子任务层面和轨迹层面，通过跨检索轨迹的共现对技能进行排序。周期性的结构感知维护通过质量加权传播修剪低效用节点并合并冗余技能。在xBench、GAIA和WebWalkerQA上使用GPT-4o和Qwen3-30B-A3B进行的实验中，HyperSkill优于十种记忆基线，在GAIA上最高提升+11.51，在WebWalkerQA上最高提升+11.18。

## Abstract
As agentic tasks grow in complexity, LLM agents increasingly rely on experiential memory to reuse procedural knowledge across tasks. Effective memory design must jointly address what to store, how memory is structured and retrieved, and how memory evolves. Existing systems tackle each only partially: they store trajectories, insights, or workflows as isolated entries, discarding compositional relationships among subtasks and reusable skills; retrieve by flat embedding similarity that ignores relational signals; and maintain memory without leveraging its relational structure. We propose HyperSkill, a hypergraph-based memory framework that jointly improves all three. HyperSkill represents memory as a hypergraph with two node types, subtask steps and reusable skills, where each hyperedge links the subtasks and skills from a single trajectory. Dual-path retrieval queries both subtask and trajectory levels, ranking skills by co-occurrence across retrieved trajectories. Periodic structure-informed maintenance prunes low-utility nodes and merges redundant skills via quality-weighted propagation. Across xBench, GAIA, and WebWalkerQA with GPT-4o and Qwen3-30B-A3B, HyperSkill outperforms ten memory baselines, yielding gains of up to +11.51 on GAIA and +11.18 on WebWalkerQA.

- **背景**：LLM智能体在长时程网页导航、交互式计算机使用、多步科学推理等复杂任务中，单次交互往往不足以稳健地解决问题，因此智能体记忆系统受到广泛关注。其中，**经验记忆**尤为关键：它不编码外部事实，而是将智能体自身过去的轨迹蒸馏为可复用知识，使智能体能够"自我进化"——每完成一条轨迹就变得更熟练，而非从零开始。
- **核心问题**：现有经验记忆系统虽已有诸多探索（存储原始轨迹、工作流、推理策略、可执行技能等），但面临三个尚未被联合解决的子问题：
  1. **存储什么**：多数系统把轨迹/洞察/技能作为孤立条目存储，**丢弃了子任务与技能之间的组合关系**；
  2. **如何结构化与检索**：主流做法是扁平向量库+嵌入相似度检索，**无法表达技能与子任务模式之间多次成功共现的n元关系**；
  3. **记忆如何演化**：多数系统无条件累积知识，少数虽做剪枝/去重，但**各自独立操作于单个节点，未利用关系结构**。
- **核心洞察**：一条轨迹本质上不是单一知识单元，而是"子任务—技能—结果"之间的**n元关联**，扁平列表和成对图只能有损地表示这种结构，而**超图**天然支持一条超边同时连接多个节点。
- **整体意义**：论文提出以超图统一管理经验记忆的存储、检索与演化三个维度，为自进化智能体的经验复用提供了新的结构范式。

## 2. 方法论

### 2.1 核心思想
- 将经验记忆组织为超图 **G = (V, E)**：
  - **两类节点**：子任务节点 Vu（编码任务分解中的组合式工作流结构）与技能节点 Vs（编码可跨任务迁移的执行策略；成功轨迹产生正向策略，失败轨迹产生错误模式）。
  - **超边**：每条超边对应一条轨迹，连接该轨迹中出现的子任务节点与技能节点，并附有原始任务描述、蒸馏出的可迁移课程（lesson）与效用评分。
  - **节点效用评分** γ(·) 综合考虑经验成功率与步数效率：
    - γ = β·(成功次数/检索次数) + (1−β)·[1 − (平均步数 − Tmin)/(Tmax − Tmin)]，β=0.7。

### 2.2 双路径超边检索（子任务 → 轨迹）
- **子任务路径**：对当前任务做 LLM 分解得到子任务集合 P0，编码后与子任务节点嵌入做 top-ku 相似度匹配（Ru），再通过节点所属超边扩展出候选轨迹集合 Esub。该路径能发现**表层任务描述不同但程序性子结构相似**的轨迹。
- **轨迹路径**：将完整任务描述与超边表示（任务描述 ∥ 蒸馏课程）做 top-ke 相似度匹配，得到 Etraj。该路径捕捉**高层任务语义相似**的轨迹。
- **融合**：E* = Esub ∪ Etraj，其附带的蒸馏课程 Lq 作为轨迹级上下文提供给智能体。

### 2.3 技能共现排序（轨迹 → 技能）
- 从融合后的轨迹集 E* 中收集候选技能池 Rs。
- 核心创新：**按技能在检索到的超边中的共现次数 κ(v) 排序**（而非单纯嵌入相似度）——一项技能出现在越多相关轨迹中，说明它越反复在任务相关情境中奏效。
- 取 top-ks 技能 Sq（平局用嵌入相似度打破），与蒸馏课程一起作为执行上下文。

### 2.4 记忆更新与记忆演化
- **插入去重**：新技能在写入前与已有技能计算相似度，超过阈值 δdedup（0.9）则合并到最近邻，而非产生重复节点。
- **质量驱动剪枝**：每 ⌈0.1×N⌉ 个任务触发一次维护；对检索次数 ν(v) ≥ Nmin 且效用 γ(v) < τprune（0.2）的节点从超图中删除。
- **结构感知合并**：仅对技能节点进行——构建质量加权共现矩阵 W（Wij = min(γ(vi), γ(vj)) · Σ 1/|Ve|，按超边大小归一化），通过 L 步对称传播得到结构嵌入 Z̃，相似度超过 δmerge（0.85）的技能对由 LLM 合并为更高阶技能，并重新分配所有超边成员关系。

## 6. 主要结论与发现

- **一致且显著的性能提升**：HyperSkill 在几乎每个"基准×骨干"组合上取得最高成功率；相对 No Memory，GAIA 最高 +11.51，WebWalkerQA 最高 +11.18（Qwen3-30B-A3B 下）；在 GPT-4o 下相对第二好方法 xBench +3.00、GAIA +2.30、WebWalkerQA +0.59。
- **高成功率不需膨胀执行成本**：例如 GPT-4o 在 xBench 上以最少步数（5.27）达到最高成功率，而 ReasoningBank、Voyager 等消耗更多步数/工具调用却性能更低。
- **朴素记忆累积可能有害**：多个基线在部分设置下低于 No Memory（如 Cheatsheet 在 xBench 上 −9.00），印证了结构感知记忆演化（剪枝+合并）的必要性。
- **消融与敏感性**：双路径检索互补——去掉子任务检索对 xBench/GAIA 伤害最大，去掉轨迹检索对 WQA 伤害最大；较小检索预算（k=2）与轻度维护（ρ=0.1）最优。
- **自进化与鲁棒性**：HyperSkill 是唯一展现持续上升累计成功率的模型；自评判设置仍保有 GT 评判 87.7%–96.8% 的性能，说明共现排序对标签噪声有韧性。

## 9. 未来工作方向

- **与外部知识联合建模**：当前超图只存储任务经验，未与外部知识库、知识图谱或代码库结合。未来可探索“技能超图 × 领域知识”的联合检索与推理，使技能既能跨任务迁移，又能与静态知识相互校验，减少幻觉技能的固化。
- **可微记忆与端到端优化**：论文检索/排序流程仍依赖启发式超参（k、β、阈值等）。未来可将超图检索设计为可微组件，在强化学习或监督微调中联合优化“写入—检索—执行”全链路，使记忆的存取策略随任务分布自适应。
- **不确定性建模与人工兜底**：自评判仅依赖单一信号区分技能正负，存在噪声风险。可引入多源置信度评估（如自我一致性、多模型投票、环境反馈置信区间），在不确定性较高时放慢记忆写入或触发人工审核，防止错误经验侵蚀记忆库。
- **多智能体共享记忆**：超图很有潜力作为多智能体共享经验基础设施，支持跨主体的技能复用与分工。未来需研究技能在不同智能体间的竞争、协同、归属与安全约束（如防止恶意技能污染共享超图）。
- **更长期限的演化分析**：论文维护周期约 0.1×N 个任务，属于中短期分析。将来可在成千上万条轨迹的规模上观察记忆收敛性、节点上限、维护开销增长，以及技能合并会不会最终退化到“少数几条过抽象技能”而损失细节。

## 10. 总体评价

总的来说，HyperSkill 是自进化 LLM 智能体记忆研究中的一项扎实且具有启发性的工作。它的主要贡献不在于某一单个模块的突破，而在于**提出了一套统一的记忆组织范式**——用超图把轨迹中的子任务模式、可迁移技能与结果信号之间的 n 元组合关系显式编码，并以此贯穿存储、检索与演化三个环节。相比扁平向量库、成对图以及纯累积式记忆系统，这一设计在结构表达力上更为自然，在检索信号上引入了共现频率这一互补维度，在记忆维护上实现了拓扑感知的剪枝与合并。

实验设计覆盖面较广，既有专有/开源双骨干验证，又有轨迹级、工作流级、图结构类等 11 个基线的横向对比，并补充了成本、延迟、敏感性与自进化趋势分析。其结论——结构感知的记忆演化优于粗放累积，共现排序优于纯语义排序——具有较强说服力和实用参考价值。

当然，论文在统计严谨性（缺少标准差与显著性检验）、任务覆盖广度（仅限网页导航与多步推理）、低数据冷启动等方面仍有提升空间。但就它提出的核心命题而言——“经验记忆应被视为超图，而非列表或成对图”——HyperSkill 为该领域提供了一个值得借鉴的范式转变。
