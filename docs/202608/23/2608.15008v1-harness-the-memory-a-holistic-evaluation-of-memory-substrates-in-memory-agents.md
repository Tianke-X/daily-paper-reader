## 摘要
记忆正成为长周期大语言模型智能体的核心基础设施，然而现有评估对于在不同运行机制下应使用哪种记忆基质（即记忆表示和存储的底层介质）提供的指导有限。我们针对记忆增强型智能体的记忆基质提出了一种受控的台架评估，涵盖密集与稀疏索引、文本记录、结构化存储、层次化存储、基于精炼的记忆、参数更新以及激活兼容的上下文机制。在三种骨干模型和四个基准套件（涵盖以用户为中心的事实问答和以智能体为中心的决策制定）中，我们在统一台架下测量了26项性能与效率指标。结果表明，没有一种单一基质能持续占据主导地位：广泛的检索有利于长上下文事实问答，而过度检索可能通过将注意力从行动关键上下文转移开而损害顺序决策。可扩展性引入了进一步的路由轴，因为在中等历史长度下表现良好的基质在更长视野下可能变得昂贵或脆弱。这些发现促使基质路由成为自适应智能体记忆系统的必要组成部分，并为设计高效、可靠且具备机制感知的大语言模型长期记忆提供了经验指导。代码将在录用后公开。

## Abstract
Memory is becoming core infrastructure for long-horizon LLM agents, yet existing evaluations offer limited guidance on which memory substrate, namely the underlying medium in which memory is represented and stored, should be used under different operating regimes. We present a controlled harness evaluation of memory substrates for memory-augmented agents, covering dense and sparse indices, text records, structural stores, hierarchical stores, refinement-based memories, parametric updates, and activation-compatible context mechanisms. Across three backbone models and four benchmark suites spanning user-centric question answering and agent-centric decision-making, we instrument 26 performance and efficiency metrics under a unified harness. Our results show that no single substrate consistently dominates: broad retrieval benefits long-context factual QA, while excessive retrieval can harm sequential decision-making by shifting attention away from action-critical context. Scalability introduces a further routing axis, as substrates that perform well at moderate history lengths can become costly or brittle at longer horizons. These findings motivate substrate routing as a necessary component of adaptive agent memory systems and provide empirical guidance for designing efficient, reliable, and regime-aware long-term memory for LLM agents. ## 2. 方法论（核心思想、技术细节）

- **核心思想**：将记忆基质（memory substrate）作为唯一实验变量进行受控评估，采用外部记忆与内部记忆的二分法分类体系，在统一的 harness 下隔离基质效应。
- **11种方法、7个基质家族**：
  - **外部记忆**（信息存于模型外部的数据结构，通过显式操作写入和检索）：
    - **扁平索引（Flat Index）**：M1 稠密向量（嵌入+余弦 top-k）；M2 稀疏向量（BM25）；均不调用 LLM；
    - **文本记录（Text Record）**：M3 Gist 索引（ReadAgent，LLM 生成一语句摘要，读取时选页展开）；
    - **结构化（Structural）**：M4 演化笔记（A-Mem，带语义链接与演化触发重写）；M5 双层图（LightRAG，实体-关系知识图谱+块级向量混合检索）；
    - **层次化（Hierarchical）**：M6 层次树（RAPTOR，递归聚类摘要，折叠树稠密检索）；
    - **精炼（Refinement）**：M7 蒸馏策略（ReasoningBank，判断轨迹并蒸馏可复用策略）；M8 技能包（MemSkill，经验聚类为技能束；将 PPO 控制器替换为零样本 LLM 预填充全部技能束）；
  - **内部记忆**（信息编码于模型权重或 KV-cache 激活中，隐式访问）：
    - **权重（Weight）**：M9 适配器微调（LoRA-FA，合成 QA 对做参数更新）；
    - **激活（Activation）**：M10 全上下文（原始缓冲区拼接+截断）；M11 情节聚类重预填充（EpiCache 变体，按情节聚类保留25% token 预算，读取时匹配质心并重预填充所选情节）。
- **排除设计**：MemGPT、Mem0、Zep 因辅助 LLM 成本过高（单次 LoCoMo 运行需2,700-9,000次辅助调用、11-23小时）被移出主对比，仅在附录报告其生产成本。
- **26项指标**：性能指标 P1-P12（Exact Match、Token F1、BLEU-1、LLM法官、压缩比、Recall@k、任务成功率、目标条件成功率、步数、Pass@1、SubEM 等）与效率指标 E1-E15（内存大小、推理时间、写入延迟、检索延迟、各阶段 token 消耗与调用次数、总耗时等15项）。
- **消融设计**：
  - top-k 检索深度扫描：LoCoMo 上 k∈{1,2,5,10,20}，ALFWorld 上 k∈{1,2,3,4,5}，并设无记忆基线；
  - 上下文窗口压力测试：在 MAB CR 上扫描 6K/32K/262K token 三种长度；
  - 注意力探针：分析响应 token 对系统/检索块/任务上下文/提示线索四个区域的注意力分配。

## 3. 实验设计（数据集、基准、对比方法）

- **骨干模型**（3个）：Qwen3-8B、Qwen3-32B-AWQ、Gemma-4-26B-A4B-IT，全部四个基准上均测试。
- **用户中心基准**（回忆导向，广泛检索有利）：
  - **LoCoMo**：10个多会话对话，1,986个问题，5种问题类型；
  - **MemoryAgentBench (MAB)**：拆分为四种能力——准确检索（AR，用 LongMemEval-S 子集，300查询）、长程理解（LRU）、测试时学习（TTL）、冲突消解（CR）；CR 兼作可扩展性探针。
- **智能体中心基准**（动作执行，检索噪声有害）：
  - **ALFWorld**：134个 unseen 具身规划任务，报告任务成功率（TSR）、步骤数、部分成功平均分；使用100条 AgentGym 成功轨迹+100条 Qwen3-32B 真实失败组成的离线库；
  - **BigCodeBench-Hard**：148个代码任务，真实 PYTEST 执行评分，跨任务解决方案池做检索。
- **对比方法**：11种基质 M1-M11 在统一 harness、相同提示、相同辅助 LLM（GPT-4o-mini）下对比；设置 NoMem 无记忆基线。
- **数据对齐验证**：通过余弦相似度验证了两个智能体中心基准的检索库与测试池的语义对齐（ALFWorld 均值0.879、BigCodeBench 均值0.594，均比随机基线高一个数量级）。

## 6. 主要结论与发现

- **结论一：单一基质无法通吃所有机制。** M5（双层图）在 LoCoMo/LME-S 对话 QA 上领先（Qwen3-32B 上 P4=0.683），但在智能体任务中被扁平检索和精炼方法超越；M7（蒸馏策略）在 ALFWorld 上夺冠（TSR=32.1%）却在 QA 上平庸。
- **结论二：检索广度在两种机制下方向相反。**
  - LoCoMo 上 P4 随 k 单调上升——每个额外检索都增加找到证据句的概率，多余上下文可被忽略；
  - ALFWorld 上任务成功率随 k 下降（M7 从 k=1 的32.1% 降到 k=5 的约25%；扁平检索跌到无记忆基线22.4% 以下），步骤数攀升——过度检索导致智能体"游荡"。
  - **注意力探针解释机制**：两种任务上注意力从任务上下文向检索块转移的机制相同，但答案所在区域不同——QA 的答案在检索块中（转移=好事），ALFWorld 的决策依赖当前观察与合法动作列表（转移=坏事）。
- **结论三：可扩展性是第三条路由轴。** 精炼类（M8）在 6K→262K token 增长中质量从0.32升到0.51且延迟仅从约1秒增至约10秒（固定大小技能束，读成本与输入长度无关）；结构化类（M4/M5）在262K 时因图重建与实体抽取成本随输入规模膨胀而付出高昂延迟代价；M10 全上下文质量随长度上升但读取成本线性增长；M9（LoRA）因缺乏选择性时序更新能力而性能持平原地（0.18-0.22）。
- **设计规则**：以写深度换读广度——每次查询少检索，在写入时投入更多精力蒸馏和结构化记忆。
- **总体含义**：通用智能体记忆必须实现为多基质或多智能体系统，按运行机制将异构基质组合和路由。

## 7. 局限性

- **基准覆盖仍有限**：虽然四个基准覆盖了用户中心与智能体中心两类机制，但尚未包含网页导航、工具调用、多智能体协作等更多真实场景；作者对2023-2026年52个系统的景观调查也可能遗漏了最新兴起的记忆方法（如基于KV cache编辑或RNN式线性注意力的方案）。
- **骨干模型与辅助模型偏斜**：三个骨干均为开源模型，未覆盖调查中占主导的GPT系列（81%系统使用），因此无法完全排除“基质与骨干模型交互效应”的遗漏；辅助LLM与法官模型均固定为GPT-4o-mini，未做替代模型敏感性分析，写入质量和评判质量可能耦合。
- **实现配置未充分调优**：每种基质采用其默认或作者惯用的配置，未对RAPTOR聚类数、LightRAG图构建阈值、A-Mem演化触发条件等做网格搜索，可能低估部分方法的最佳表现；稠密与稀疏检索器也未做混合（如RRF融合）的扩展测试。
- **被排除系统的性能缺失**：MemGPT、Mem0、Zep因辅助调用成本过高未进入主对比，仅在附录报告生产成本，读者无法知道它们在质量维度上是否具备竞争力——这削弱了“生态位全覆盖”的宣称。
- **统计报告方式**：主结果以点估计呈现，未提供置信区间或显著性检验（作者以样本量和非参数检验的稳定性作为合理性论证），对方法间差距的稳健性评估不够严密；MAB中部分子集查询数（300）规模偏小，可能放大噪声。
- **可扩展性探针单一**：上下文窗口压力测试仅在MAB CR子集上进行，未在LoCoMo或ALFWorld上验证缩放规律是否一致，结论的外推性受限。

## 8. 对研究社区与实践的启示

- **对研究者的启示**：
  - 评估记忆系统应同时报告性能与效率指标——论文展示的26项指标框架（P1-P12、E1-E15）可作为未来工作的标准化评估模板；
  - “基准集中、指标单一、骨干单一”三大缺陷应成为新基准建设的反对照，智能体中心基准（ALFWorld、BigCodeBench-Hard类）应被纳入常规记忆评估；
  - 注意力探针作为一种可解释机制分析工具被证明有效，未来研究可将其用于解释其他基质的设计差异，而非仅比较黑箱分数。
- **对系统设计者的启示**：
  - 对话回忆场景（用户中心）优先选用结构化图谱或层次化索引；
  - 具身规划和动作执行场景（智能体中心）应使用扁平检索+小top-k或技能蒸馏，避免检索噪声；
  - 面对长期增长的数据，以“写深度换读广度”为原则，优先考虑固定大小的技能包/策略库而非随输入规模膨胀的结构；
  - 忽略上下文的模型（如LoRA微调）在记忆任务中效果有限，不应作为通用记忆基质首选。
- **对通用智能体架构的启示**：单一记忆基质无法主导所有机制，通用记忆模块应当是一个包含多个异构基质的组合系统，并配备面向任务的**基质路由器**（substrate router）——论文为这一路由器提供了首个实证路由信号（机制类型、检索深度、上下文规模三个路由轴）。

## 9. 总结与总体评价

- **核心贡献**：这是已知首个在统一harness下对11种跨七大类的记忆基质做受控交叉评估的研究，在26项指标上完成3骨干×4基准×11基质的系统实验，填补了记忆系统“无统一公平比较”的空白；其“外部记忆 vs 内部记忆”二分法和“机制-基质匹配”框架为后续研究提供了清晰的概念坐标。
- **证据强度**：结论具有多重证据链——主对比矩阵、检索深度扫描、上下文缩放实验与注意力探针四类证据相互印证，使“单一基质无法通吃”“检索广度方向相反”“可扩展性是第三路由轴”三条核心结论可信度高。
- **实践价值**：论文给出的设计规则（写深度换读广度、按机制路由）以及26项指标框架可直接迁移到工业级智能体记忆系统开发中，具有较高的工程落地参考价值。
- **总体判断**：方法设计严谨、覆盖面广、洞察深刻，是一次高质量的基准评估研究；但受限于基准种类、骨干模型覆盖和统计报告方式，其结论的普适性仍需在更广的任务分布与模型生态中进一步验证。其提出的“基质路由”概念有望成为通用记忆系统设计的后续基石方向。
