## 摘要
传统的检索增强生成（RAG）框架在处理文档时不关注其层级结构，导致性能不佳，尤其是在孟加拉语等低资源语言中。为解决这一问题，我们提出了一种结构感知的RAG框架，将孟加拉语教科书建模为层级图，并使用对比训练的图神经网络检索一小部分相关段落。这些段落为大型语言模型提供了聚焦上下文，从而支持主题特定的多项选择题（MCQ）生成和领域内的答案预测。实验结果表明，我们的框架在检索指标上优于强密集检索基线，生成更相关的MCQ，并实现更优的答案预测准确性。

## Abstract
Traditional retrieval-augmented generation (RAG) frameworks process documents without attending to their hierarchical structure, leading to poor performance, especially in low-resource languages such as Bengali. To address this, we propose a structure-aware RAG framework that models Bengali textbooks as hierarchical graphs and uses a contrastively trained graph neural network to retrieve a small set of relevant passages. These passages provide focused context for a large language model, enabling topic-specific multiple-choice question (MCQ) generation and in-domain answer prediction. Experimental results demonstrate that our framework outperforms strong dense retrieval baselines across retrieval metrics, produces more relevant MCQs, and achieves superior answer prediction accuracy.

## 方法论

### 核心思想
将教科书构建为**带层级、顺序和语义关系的异构有向多图**，通过**对比训练的图注意力网络（GAT）**学习节点（尤其是段落节点）的语义表示，以精确检索与主题/问题最相关的段落，作为 LLM 的聚焦上下文。

### 关键技术细节与流程
1. **文档处理**：对 4 本孟加拉语中学教科书（2 本文科、1 本生物、1 本社科）进行 OCR 文本提取，保留原有的段落结构。
2. **合成训练数据创建**：利用 Gemini 3.1 Pro 和 GPT-4 等 LLM 生成约 22,000 对「查询-正相关段落」对，用于 GNN 的监督训练。
3. **图构建**：
   - 节点：章节、标题、副标题、段落、句子。
   - 边：论文从以下三种类型的边描述图结构：
     - **层级边（Hier）**：连接父子层级节点，允许在文档层级间传递消息；
     - **顺序边（Seq）**：连接同一层级内顺序相邻的节点，捕捉书本章节的顺序流程；
     - **加权语义边（Sem）**：在句子节点之间，与 top-K 个最相似邻居相连，权重设为余弦相似度（阈值 T）。
4. **GNN 架构与训练**：
   - 采用自定义的**多注意力头图注意力层**，统一处理加权/未加权边。注意力得分公式为：
     e<sub>ij</sub> = [x′<sub>i</sub> ∥ x′<sub>j</sub>] · a + λ·w<sub>ij</sub> + b<sub>type</sub>
     其中 w<sub>ij</sub> 是语义边权重，λ 为可学习标量，b<sub>type</sub> 为边类型偏置。
   - 三个 GAT 层堆叠，输出与原节点嵌入拼接后，经 MLP 融合回 1024 维，缓解过平滑问题。
   - 训练目标采用**多正例 InfoNCE 对比损失**，使查询与其所有相关段落的表示接近，同时远离无关段落。
5. **检索与接地**：
   - 推理时，用训练好的 GAT 对全文段落进行排名，取 Top-10，再用 BGE-Reranker-V2-M3 交叉编码器重排，最终保留 Top-5 段落作为 LLM 的接地上下文。
   - 该流程有效压缩了上下文长度（从 43,591 tokens 降至 1,651 tokens），同时保持高覆盖率。

## 主要结论与发现

- **图结构检索显著优于非结构检索**：最优 GAT(5, 0.5) 在所有检索指标上显著超越无重排的密集检索基线（如 Fine-tuned BGE-M3），验证了结构感知的有效性。
- **少即是多**：GAT + BGE-Reranker 仅用 Top-5 段落的 nDCG@5 即超过 Fine-tuned BGE-M3 + Reranker 用 Top-10 段落的 nDCG@10，说明图引导检索能在**降低上下文规模的同时提升精度**。
- **端到端性能大幅提升**：GAT + Reranker 将平均上下文长度从 43,591 降至 1,651 tokens（压缩约 96%），同时 MCQ 的主题相关性（TR）达到最高（0.67），答案预测准确率最高（91.41%），为所有方法中最高。
- **层级边至关重要**：消融实验显示，去除层级边后检索性能几乎崩溃（Recall@5 从 0.829 骤降至 0.012），证明层级结构是模型学习的最关键信号；去除顺序边和语义边的性能影响相对较小。
- **设计选择均有明确效果**：可学习温度参数、合适的 K<sub>s</sub>/T 配置对检索性能有正向影响；硬负样本挖掘在该场景下反而显著损害性能（Recall@5 < 50%）。
- **专家认可生成质量**：82.1% 的生成 MCQ 被评为相关（评分 ≥ 3），其中生物领域表现最佳（92.5%）。

## 不足与局限

1. **合成数据依赖**：GNN 训练完全依赖 LLM 生成的合成查询-段落数据，存在幻觉/噪声传导风险，作者也承认这一点，并指出完全人工策划的数据集将会是更可靠的训练信号来源。
2. **自动评估难以避免偏差**：IWF、QF、DS、TR、PPL 等自动指标均依赖 LLM 或嵌入模型作为评判器，带有评判模型本身固有偏差，只能近似反映真实质量。
3. **人类评估规模不足**：仅 2 名专家、140 个 MCQ 样本，跨领域一致性仅 κ=0.55（中等），缺乏多评分者、更大样本的可泛化性证据。
4. **泛化边界不清**：实验仅基于 4 本教科书、3 个学科。对其他语言、其他教材类型（如大学教材）、其他体裁文档的迁移能力未作验证。
5. **算力信息缺失**：未报告训练时间、GPU 消耗等，难以评估复现成本和技术可及性。
6. **受限于当时模型能力**：实验依托 Gemini 3.1、GPT-4、GPT-5.2 等专有模型，其评估和生成结果随着模型版本迭代可能缺乏可复现性。
