## 摘要
在大语言模型中改进知识使用的方法通常分为两种机制。非参数检索提供了对外部知识的灵活访问，但增加了检索延迟、上下文开销，并且与主干的集成较浅。参数化适配在推理时高效，但将知识与模型权重纠缠在一起，难以更新、审计或迁移。Engram风格的哈希记忆占据了一种中间机制：它将学习到的信息存储在外部可寻址的表中，但通过一个小型学习型阅读器来消费该表。这引出了一个基本问题：当这种记忆跨骨干模型移动时，更关键的是冻结的记忆本身还是目标端阅读器？我们通过跨模型冻结记忆提取来研究这个问题，其中在源模型上训练的记忆被冻结并附加到不同的目标模型上，仅训练一个轻量级阅读器。消融实验表明，学习到的记忆内容和正确的寻址都重要，但迁移的表只有通过与目标模型对齐的阅读器才能变得有用。在下游问答任务中，一个双层四分支阅读器几乎弥合了同模型与跨模型重用之间的差距，在我们受控评估协议下平均得分为38.8。此外，当提供者的阅读器与目标接口直接兼容时，冻结的工件无需目标端训练即可提供实质性效用，而可选的阅读器适配则带来进一步提升。这些结果表明，只要目标端可以访问兼容的阅读器接口，Engram就可以作为可重用的外部知识工件；当直接重用阅读器不足时，目标端适配可以进一步改善对齐。

## Abstract
Methods for improving knowledge use in large language models typically fall into two regimes. Non-parametric retrieval offers flexible access to external knowledge, but adds retrieval latency, context overhead, and only shallow integration with the backbone. Parametric adaptation is efficient at inference time, but entangles knowledge with model weights and can be hard to update, audit, or transfer. Engram-style hashed memory occupies a middle regime: it stores learned information in an external, addressable table, yet consumes that table through a small learned reader. This raises a basic question: when such a memory is moved across backbones, what matters more, the frozen memory itself or the target-side reader? We study this question through cross-model frozen-memory extraction, in which a memory trained on a source model is frozen and attached to a different target model, with only a lightweight reader trained. Ablations show that learned memory content and correct addressing both matter, but the transferred table becomes useful only through a reader aligned to the target model. In downstream question answering tasks, a dual-layer, four-branch reader nearly closes the gap between same-model and cross-model reuse, achieving an average score of 38.8 under our controlled evaluation protocol. Moreover, when the provider reader is directly compatible with the target interface, the frozen artifact can provide substantial utility without target-side training, while optional reader adaptation yields further improvement. These results suggest that Engram can serve as a reusable external knowledge artifact, provided that the target has access to a compatible reader interface; target-side adaptation can further improve alignment when direct reader reuse is insufficient.

## 2. 方法论：跨模型冻结记忆提取

### 2.1 核心思想

- 将 Engram 式外部记忆视为可迁移工件：
  - **源记忆表冻结**：源模型训练完成后，导出并冻结记忆表。
  - **目标侧仅训练阅读器**：目标模型和冻结记忆均不更新，只学习轻量级目标端阅读器。
- 研究将知识使用分解为三个角色：
  1. **寻址（addressing）**：决定读取哪个记忆槽位；
  2. **记忆（memory）**：存储的向量本身；
  3. **阅读器（reader）**：将记忆向量映射进目标模型隐藏空间。

### 2.2 关键技术细节

- **Tokenizer 无关寻址（Tokenizer-Agnostic Addressing）**：
  - 原生 Engram 使用模型特定 token ID 进行哈希，导致不同 tokenizer 下同一段文本可能路由到不同记忆槽位。
  - 论文采用**规范化管道**：先对解码文本做 NFKC 规范化、小写化、去重音、空白清理，再提取“词边界 n-gram”，最后用确定性哈希得到记忆索引。
  - 对中文、日文等无明确空格分隔的语言，改用规范化后的字符跨度（character-span）进行哈希。
- **目标端阅读器结构**：
  - 每个注入层包含共享值投影和多个键投影分支。
  - 分支数量 R 控制目标端对齐能力，但不会增加记忆表大小。
  - 门控采用上下文相关 sigmoid，使模型可以抑制不相关或不对齐的记忆。
  - 输出通过残差连接注入目标模型：\( h_{t,\ell} \leftarrow h_{t,\ell} + o_{t,\ell} \)。
  - 更强配置为“双层 + 四分支”阅读器（两层注入，每层 4 个分支）。
- **训练流程**（Algorithm 1）：
  - Phase 1：源模型与记忆在语料上联合做 next-token prediction。
  - Phase 2：冻结源记忆和目标骨干，仅训练目标端阅读器。
  - 部署模式：**直接工件复用**（目标端零训练）与**阅读器适配复用**（目标端轻量训练）。

## 6. 主要结论与发现

- **冻结记忆确实可跨模型迁移**：所有 9 个源-目标组合上，目标模型困惑度均较无记忆基线下降，相对改善从 1.6% 到 15.7% 不等。
- **迁移成功依赖目标端阅读器**：
  - 阅读器结构是第一阶因素：双层注入比单层大幅提升 QA；四分支比单分支进一步改善。
  - 记忆内容与寻址同样重要：置乱键导致 QA 大幅退化，随机记忆显著弱于迁移记忆。
- **跨模型与同模型重用差距可被缩小**：最强双层四分支阅读器使跨模型平均 QA 达到 38.5–38.8，接近同模型表现。
- **直接复用兼容阅读器可行**：当源阅读器与目标接口兼容时，冻结工件无需目标端训练即可显著提升性能；额外适配可进一步小幅提升。
- **迁移增益是任务相关的**：
  - 对 NQ、WebQA、TriviaQA、HotpotQA、RTE、SciQ 等事实性/证据型任务改善明显；
  - 对 RACE 等阅读理解影响不大；
  - 对 TruthfulQA 反而轻微有害，因为该任务需要模型抵抗常见误解，而非依赖更多记忆关联。
- **迁移主要提供更好的目标端初始化，而非更高的渐近上限**：从零训练目标记忆最终也能达到类似性能，但需要更多目标端数据。
- **答案 token 级分析**：迁移记忆并非简单地在答案位置直接注入正确答案，而是通过改善整体事实支撑状态间接提高正确答案支持度。

## 8. 不足与局限

- **模型规模有限**：最大源/目标模型为 9B，未系统测试超过 10B 甚至 100B 级别的记忆迁移行为。
- **缺乏统一缩放规律**：未给出阅读器深度、分支数、注入位置、参数规模与骨干/记忆规模之间的缩放定律。
- **阅读器设计空间未穷尽**：只评估了线性、共享值投影等多分支结构，未探索非线性变换、自适应分支聚合、动态注入层选择等更多可能性。
- **寻址语言覆盖有限**：词边界方式对无空格语言不适用；字符跨度方案只在中文/日文上验证，对字节级 tokenizer、混合脚本、噪声 Unicode 等仍可能不够稳健。
- **目标端数据效率结论依赖有限场景**：Pythia 与 Qwen 的缩放分析规模较小，下游收益“任务依赖”的机制未完全解释。
