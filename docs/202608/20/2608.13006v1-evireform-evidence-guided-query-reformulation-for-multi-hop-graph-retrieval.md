## 摘要
多跳检索必须找回能共同提供充足证据的段落。初始段落往往解析了问题中隐含的实体或关系，使得缺失的证据只有在检索开始后才更易描述。图检索通过存储的语料库结构提升了访问相关证据的能力，但其检索信号通常源自原始问题。即使观察到的段落提供了更直接的语义线索，互补证据仍须通过存储的关系来获取。我们提出了EviReform，它将修订检索请求与在图内聚合证据分离开来。检索到的源段落为未解决的信息需求构建残差查询。原始检索信号与残差检索信号分别归一化、组合，并在共享实体的命题之间传播。在2WikiMultiHopQA、HotpotQA和MuSiQue上，EviReform相比最强基线最高可提升5.59个Recall@5点和4.50个F1点。这些结果表明，观察到的证据可以引导图检索趋向于原始问题未充分指定的支持链部分。代码见https://github.com/XrazyMee/EviReform。

## Abstract
Multi-hop retrieval must recover passages that provide sufficient evidence together. An initial passage often resolves an entity or relation implicit in the question, making the missing evidence easier to describe only after retrieval begins. Graph retrieval improves access to related evidence through stored corpus structure, but its retrieval signal is commonly derived from the original question. Complementary evidence must then be reached through stored relations even when an observed passage provides a more direct semantic cue. We introduce EviReform, which separates revising the retrieval request from aggregating evidence in the graph. Retrieved source passages formulate residual queries for the unresolved information need. The original and residual retrieval signals are normalized separately, combined, and propagated between propositions that share entities. On 2WikiMultiHopQA, HotpotQA, and MuSiQue, EviReform exceeds the strongest baseline by up to 5.59 Recall@5 points and 4.50 F1 points. These results show that observed evidence can guide graph retrieval toward the part of a supporting chain left underspecified by the original question. Code is available at https://github.com/XrazyMee/EviReform.

### 论文核心问题与整体含义（研究动机和背景）

多跳检索（Multi-Hop Retrieval）的目标是恢复那些**共同构成完整证据链**的段落。一个关键观察是：初始检索到的段落往往解析了问题中隐含的实体或关系（即“桥接”），这使得缺失的互补证据只有在检索开始之后才变得容易描述。尽管以图结构（GraphRAG）为基础的检索系统（如 PropRAG、HippoRAG 2、CatRAG）通过存储的语料库结构改善了相关证据的访问，**其核心检索信号通常仍仅源自原始问题**。这意味着，即便已观察的段落为缺失信息提供了更直接的语义线索，检索器仍必须单纯依赖图结构中预存的关系来寻找互补证据，从而错失利用观察结果优化检索请求的机会。

论文将两个通常被混在一起处理的操作明确分离：**一是在读取任何段落之前，用原始问题确定图检索的入口与路径；二是在读取段落之后，利用其内容重新定义新的文本证据需求**。据此，论文提出 EviReform，一种让观察到的证据引导图检索、修正检索信号的框架，从而更有效地定位原始问题未充分指定的支撑链部分。

### 论文提出的方法论

EviReform 的核心思想是**将“修订检索请求”（Query Reformulation）与“在图内聚合证据”（Evidence Aggregation）分离**。其流程大致如下：

1. **命题-实体索引构建**：使用 LLM 将语料库中的每个段落分解为自包含的原子命题（propositions），并从每个命题中提取实体提及。由此构建命题-实体关联矩阵 A、命题到段落的归属映射 π 及命题的归一化嵌入向量。

2. **初始证据选择**：使用原始问题 q 的嵌入向量对所有命题进行相似度打分，再由 LLM 从得分最高的 Top-100 命题中选择一组（至多 12 个）命题 Sq。这些命题构成原始问题的检索种子信号 b(q)，其完整来源段落形成观察到的证据集合 Eq。初始选择阶段**不占用最终输出的排名位置**，其目的仅在于暴露证据以指导后续搜索。

3. **从观察证据重构查询**：EviReform 将 `(q, Eq)` 传给 LLM，生成至多 L 个“残差查询”（residual queries）集合 `ρ = {ρ1, …, ρL}`。这些查询描述的是原始问题需要、但 Eq 尚未确立的信息需求，而非重述问题或直接给出答案。

4. **信号组合**：通过稠密检索为每个残差查询挑选一组命题，经独立归一化后得到残差信号 `r(ℓ)`。原始信号与残差信号按权重 β 组合为 `s = β·b(q) + (1-β)·r`。**分别归一化**能防止残差查询的数量或原始分数规模压制原始问题的约束。若残差查询无效，则退化为仅使用原始信号。

5. **共享实体传播**：组合后的信号在共享实体的命题之间进行一次传播（one-step propagation），即计算 `z = α·s + (1-α)·T·s`，其中 T 是由命题-实体关联矩阵推导出的转移矩阵。这样，与任一信号通道相关的命题都能通过结构关联共同影响最终排序。

6. **段落读出**：最终将命题得分聚合成其源段落的得分，公式为 `score(dj) = (1/√|Pj|) · Σ zi`，其中 `|Pj|` 是段落中提取的命题数。该因子避免了段落因被拆分成更多命题而获得不公平的优势，并最终返回一个统一的段落排名。

关键公式（文中编号）包括：
- `rel(d | q, E_q) ≠ rel(d | q)`：观察证据改变了相关性的定义。
- `z = B^T P_G s(q, E_q)`：在图结构上对组合信号进行传播。
- `W = A D_e^+ A^T - diag(A D_e^+ A^T)`：构建去除自环的命题关联权重。
- `z = αs + (1-α)Ts`：直接信号与传播信号的加权混合。

  - 迭代与智能体检索：IRCoT、S2G-RAG、GeAR；
  - 图检索：PropRAG、HippoRAG 2、CatRAG；

### 主要结论与发现

1. **显著性能提升**：在三个多跳 QA 数据集上，EviReform 在 R@5 上比最强基线分别高出 5.00、2.65、5.59 个百分点，在 F1 上高出 3.91、2.28、4.50 个百分点。配对 bootstrap 区间证实多数提升具有统计显著性。
2. **完全链条恢复是主要提升点**：在 Hit@5 接近饱和（>99%）的情况下，EviReform 将 Chain@5 大幅提高了 22.5（2Wiki）、12.1（HotpotQA）、11.7（MuSiQue）个百分点，这说明其优势在于**恢复完整证据链**，而非仅检索到单个相关段落。
3. **重构贡献大于传播**：消融结果显示，查询重构（残差查询）是恢复新证据的主要来源；图传播则提供较小但一致的增益（+0.6~0.93 R@5）。
4. **观察证据的价值**：匹配检索运行（重复原问题）和重排控制的效果远低于完整方法，证明增益来自于**指定未解决的信息需求**，而不仅仅是发出更多请求或对已有候选重新排序。
5. **遗留挑战**：在 MuSiQue 上，通过残差检索能发现更多完整链条（池覆盖率提升），但最终 Top-5 排名仍难以完全保留这些链条，说明“发现候选”与“构建最终集合”仍是两个不同的挑战。

### 优点

- **概念清晰**：明确区分了“查询修订”与“证据聚合”两种操作，并分别建模，避免了将二者混为一谈的常见做法。
- **方法设计合理**：残差查询设计针对“未解决的信息需求”，混合信号确保原始问题约束不被丢失；利用命题作为匹配单元提高了语义精确度，同时保留段落作为最终输出以维持上下文完整性。
- **实验严谨**：使用配对 bootstrap 提供置信区间，进行了丰富的消融与鲁棒性分析（参数、嵌入、LLM、索引增长等），并公开了详尽的复现细节和所有提示词。
- **工程细节务实**：初始选择不占用输出位置，避免观察阶段不当地保留排名空间；使用稀疏矩阵运算实现传播，控制计算成本。

### 不足与局限

- **依赖 LLM 输出**：索引构建、初始选择、查询重构均依赖 LLM（DeepSeek-V4-flash），LLM 的随机性或不同配置可能引入结果差异，而论文的统计检验未覆盖这一变异来源。
- **实验覆盖有限**：检索实验仅覆盖三个英语多跳 QA 基准，且每个数据集仅使用一个生成的索引。Medical 数据集无金标准段落，无法直接衡量检索质量。
- **MuSiQue 上的最终排名挑战**：尽管残差检索大幅扩大了覆盖完整证据链的池，但最终 Top-5 中保留完整链条仍有较大差距（池完备性与最终 Chain@5 相差 14.8 点），说明最终证据集的紧凑选择仍是未解问题。
