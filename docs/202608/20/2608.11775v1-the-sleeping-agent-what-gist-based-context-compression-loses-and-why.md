## 摘要
基于要旨的上下文压缩——将较旧的对话历史概括为紧凑表示——是长时程语言模型智能体中的常见方法，然而它对不同类型记忆检索的影响却鲜为人知。我们使用显著性加权整合（SWC），一种受睡眠记忆整合启发的生物模拟压缩框架，作为诊断探针来研究要旨压缩何时有帮助、何时有损害。SWC根据显著性对对话历史进行评分，将其划分为优先级层，并对中优先级内容应用结构化要旨抽象。在温度设为0的条件下，对所有十个LoCoMo对话上的四种条件进行评估——共计1,935个匹配的纯文本问题，在排除第5类（对抗性）问题后，主要聚合使用了1,501个问题——我们发现了一致的任务类型交互：要旨压缩在多跳推理和单跳事实问题上显著优于截断，但在压缩条件下，时间类问题仍然明显更难，在同时评估两种条件的对话中，压缩条件的得分远低于全上下文参考。我们将这一失败追溯到特定机制：要旨抽象提示保留了关系和事件结构，同时丢弃了日期和时间。对所有十个对话的保留分析证实了这一机制：通过一句话的提示修改，时间表达保留率大约增加了20倍（从3.05%到62.39%），而命名实体和事件保留率几乎没有变化（分别为x1.02和x1.11），表明这一修复是一种精确工具。该提示修改在匹配集中的第2类（时间）问题上恢复了+0.314 [0.254, 0.375]的评判准确率。代码和结果：https://github.com/kyrkewood/sleeping-agent。

## Abstract
Gist-based context compression---summarising older conversation history into compact representations---is a common approach in long-horizon language model agents, yet its effect on different types of memory retrieval is poorly understood. We use Salience-Weighted Consolidation (SWC), a biologically-inspired compression framework motivated by sleep-based memory consolidation, as a diagnostic probe to study when gist compression helps and when it hurts. SWC scores conversation history by salience, partitions it into priority tiers, and applies structured gist abstraction to mid-priority content. Evaluating four conditions on all ten LoCoMo conversations---1,935 matched text-only questions in total, 1,501 used in the primary aggregate after excluding Category 5 (adversarial) questions---at temperature 0, we find a consistent task-type interaction: gist compression substantially outperforms truncation on multi-hop reasoning and single-hop factual questions, but temporal questions remain substantially harder under compression, with compressed conditions scoring well below the full-context reference on the conversations where both are evaluated. We trace this failure to a specific mechanism: the gist abstraction prompt preserves relational and event structure while discarding dates and times. A preservation analysis across all ten conversations confirms the mechanism: an approximately 20-fold increase in temporal expression preservation (3.05% to 62.39%) with a one-sentence prompt modification, while named entity and event preservation rates barely change (x1.02 and x1.11), demonstrating that the fix is a precision instrument. The prompt modification recovers +0.314 [0.254, 0.375] judge accuracy on category-2 (temporal) questions in the matched set. Code and results: https://github.com/kyrkewood/sleeping-agent.

- **核心问题**：长时程语言模型智能体（long-horizon LLM agents）在处理超过上下文窗口长度的对话历史时，通常采用"基于要旨的上下文压缩"（gist-based context compression）策略，即用摘要模型对较旧的对话进行概括后回填。然而，这种统一压缩策略对不同类型的记忆检索（如时间性、事实性、关系性信息）的具体影响尚未被系统研究。
- **研究动机**：近期结构化记忆系统（如 LightMem、Mem0、MemMachine 等）在 LoCoMo 基准上取得了 0.7–0.9 的高分，但这些系统架构复杂，难以分离出"到底哪个组件在起作用、为什么起作用"。本文希望用简洁、可控的探针来隔离研究 gist 压缩对不同任务类型的影响。
- **整体含义**：论文发现 gist 压缩存在**任务类型交互效应**——多跳推理和单跳事实问题受益于压缩，但时间类问题被系统性损害；且该失败可追溯到摘要提示本身就未要求保留日期时间这一**可修正的设计遗漏**，而非不可解决的架构缺陷。
- **核心主张**：时间锚点（temporal anchors）应作为 gist 压缩中的**受保护类别**（protected category）被显式保留，而非依赖通用抽象提示。

### 2. 方法论：Salience-Weighted Consolidation（SWC）

**核心思想**：SWC 是一个受睡眠记忆巩固（sleep-based memory consolidation）启发的生物模拟压缩框架，用作诊断探针而非生产级记忆系统。它从睡眠神经科学中汲取三条设计原则：

- **主动调度**（proactive scheduling）：在空闲窗口而非容量上限时进行整合；
- **显著性加权保留**（salience-weighted retention）：按显著性格历史分块评分并分层；
- **分阶段压缩**（staged compression）：先进行显著性评分，再进行 gist 抽象。

**Stage 1：显著性评分**

每个会话块（session chunk）根据三个信号加权打分：

| 信号 | 权重 | 计算方式 |
|---|---|---|
| 下游相似性（Downstream similarity） | 0.4 | 块与后续轮次嵌入的余弦相似度，使用 `all-MiniLM-L6-v2` 局部计算 |
| 近因性（Recency） | 0.3 | 会话索引 ÷ 总会话数 |
| 信息密度（Information density） | 0.3 | 长度归一化的命名实体和数字数量 |

- **分层规则**：高优先级（≥0.6）→ 逐字保留；中优先级（0.3–0.6）→ gist 压缩；低优先级（<0.3）→ 丢弃。
- 最近两个会话和会话 0 始终为高优先级；若超出 4,000 token 预算，则按最低显著性优先丢弃高优先级块。

**Stage 2：Gist 抽象**

- **SWC-Full**（基础版）：使用 Claude Haiku（temperature 0）对中优先级内容进行压缩，提示要求保留说话者事实信息、因果关系、决策及理由、未完成的承诺或计划，丢弃闲聊和情绪化内容，输出 3–5 句简洁段落。**该提示未要求保留日期或时间**——这是后续被发现为失败机制的关键设计特征。
- **SWC-Temporal**（时间保护版）：与 SWC-Full 完全一致，仅在提示开头增加一句话："You MUST preserve verbatim: all specific dates, times, durations, ages, and temporal expressions (e.g. ‘7 May’, ‘last Tuesday’, ‘at 9pm’)."

### 6. 主要结论与发现

- **聚合结果**（类别 1–4，N=1,501）：SWC-Temporal 0.468 > SWC-Full 0.379 > Sliding window 0.238 > Truncation 0.171，各条件 CI 非重叠。
- **类别级结果**：
  - 多跳（Cat. 1）：SWC 条件（0.407–0.429）显著优于基线（0.157–0.271）；
  - **时间（Cat. 2）是核心失败点**：SWC-Full 仅 0.156，与 Truncation（0.137）和 Sliding（0.171）相当甚至更低；SWC-Temporal 达 0.470，与 SWC-Full 的 CI 完全不重叠；
  - 开放域（Cat. 3）：所有条件 CI 重叠，无可靠差异；

- **配对修复分析**：仅增加一句话的时间保护提示，使类别 2 判断准确率提升 **+0.314 [0.254, 0.375]**（n=315），方向在全部 10 个对话中均为正。

- **Sliding window 的基线表现**：在全部 10 个对话中匹配或超过截断（一个对话持平），但仍显著低于 SWC 条件。

### 7. 优点

- **隔离研究的实验设计**：将复杂记忆系统拆解为可控探针（SWC），能精确归因 gist 压缩的效果，避免了结构化记忆系统"什么都好但不知道哪里好"的黑箱问题。
- **机制验证的完整性**：采用"三源互证"策略——类别准确率模式（选择性失败）+ 保留率量化分析（选择性丢弃）+ 单个提示修改的恢复效果（精确修复）——三者共同锁定机制，逻辑链条严密。
- **精准的干预粒度**：仅修改一句话提示即实现 20 倍时间保留率提升，且对实体和事件保留影响极小，是干净的设计对照实验。
- **认真对待评估质量**：LLM-judge 经盲测人工验证（95% 一致率）且确认偏差方向保守；temperature 0 消除采样噪声；bootstrap CI 提供统计可靠性；排除类别 5 时给出了明确的计分规则层面的理由，而非仅图省事。
- **跨方法验证**：在全部 10 个对话上复现一致性方向（配对正值），排除了单对话偶然性。
- **可操作的实践结论**：研究直接产出一条可迁移的设计原则——"gist 压缩组件应显式保护时间锚点"——对 LightMem、Mem0 等记忆系统的设计具有直接参考价值。
- **代码和结果公开**：提供 GitHub 仓库，利于复现与后续研究。

### 8. 不足与局限

- **全上下文参考有限**：Full context 仅在会话 0–1 上评估（299 个问题），无法全面比较压缩各条件与理想天花板的差距，尤其无法判断 SWC-Temporal 距全上下文还有多远。
- **类别 3（开放域）无结论**：所有条件 CI 完全重叠，无法推断压缩策略对依赖先验知识的常识推理问题的效果。
- **保留率指标是保守代理**：逐字匹配率会低估语义上忠实的改写；实际保留的时间信息可能高于 3.05%，但论文承认这一局限且该偏斜方向只会削弱其结论而非增强。
- **可迁移性未验证**：时间保护仅在 SWC 框架内测试，未验证该提示修改是否同样改善 sliding-window 或其他记忆系统的压缩效果。
- **类别 5（对抗性）的排除存疑**：虽然理由充分（二元计分奖励内容删除），但排除了 434 个问题（占 22%），改变了基准的完整评估面；不同观点可能认为该排除让结果难以与包含类别 5 的既有工作直接比较。
- **调度设计无法在离线基准上验证**：SWC 的主动调度（idle-window）贡献在 LoCoMo 上不可测试，SWC-Reactive 的初步对比（n=3 对话）不足以验证排程贡献。
- **单点异常未完全解释**：会话 1 上 Sliding window 的类别 2 得分（0.520）反常地超过 SWC-Temporal（0.440），论文归因于小样本（25 个时间问题），但未做进一步分析。
- **计算成本与实时性**：显著性评分在 CPU 上每对话需 30 分钟至 2.5 小时，对于在线部署的代理可能构成延迟瓶颈，论文未讨论这一实际约束。
