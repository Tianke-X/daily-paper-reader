## 摘要
随着LLM智能体在结构化工作流和会话中运行，保留长期历史并不保证后续上下文能够通过有界记忆接口恢复相关证据。我们研究了长期会话记忆中的证据可达性问题，其中检索仍然在很大程度上依赖语义相似性。这对主题性回忆效果良好，但常常遗漏与后续事件语义距离较远的早期经验、计划或动机，而这些内容有助于解释后续事件。现有的记忆图提供了跨记忆结构，但主要由语义重叠驱动的链接可能会复制宿主检索器已恢复的内容。我们认为，链接构建应优先考虑一组稀疏的、与检索器互补的关联。我们提出了CABLE（基于先前的互补链接与扩展），这是一种插件式增强方法，构建旨在扩展宿主检索器直接语义覆盖范围的链接。对于每条新记忆，CABLE生成面向先前的查询，检索先前的记忆，减去直接语义邻域中的候选，并在将接受的互补关联添加到稀疏有向图之前验证其余部分。在检索时，CABLE沿这些链接扩展宿主系统检索到的种子，以揭示隐式支持证据。我们在LoCoMo和MA-LongMemEval上使用A-MEM评估CABLE，并进一步将其集成到LoCoMo上的SimpleMem和Mem0g中，使用Qwen3.5-27B、DeepSeek-chat和GPT-4o-mini。CABLE在每一个评估的系统级设置中都产生了更高的平均LLM评判分数，在有用证据分布于多个记忆或会话中的类别中提升最大，包括开放域、多会话和偏好导向的问题。这些结果支持优先考虑稀疏的、与推理相关的关联，这些关联补充而非复制宿主检索器。

## Abstract
As LLM agents operate across structured workflows and sessions, preserving long-term history does not ensure that later contexts can recover relevant evidence through a bounded memory interface. We study this evidence-reachability problem in long-term conversational memory, where retrieval still relies heavily on semantic similarity. This works well for topical recall, but it often misses earlier experiences, plans, or motivations that are semantically distant from the later events they help explain. Existing memory graphs provide cross-memory structure, yet links driven mainly by semantic overlap can duplicate what the host retriever already recovers. We argue that link construction should instead prioritize a sparse set of retriever-complementary associations. We present CABLE (Complementary Antecedent-Based Linking and Expansion), a plug-in augmentation that constructs links designed to extend the host retriever's direct semantic reach. For each new memory, CABLE generates antecedent-oriented queries, retrieves prior memories, subtracts candidates in the direct semantic neighborhood, and verifies the remainder before adding the accepted complementary associations into a sparse directed graph. At retrieval time, CABLE expands the host system's retrieved seeds along these links to surface implicit supporting evidence. We evaluate CABLE with A-MEM on LoCoMo and MA-LongMemEval, and further integrate it into SimpleMem and Mem0g on LoCoMo, using Qwen3.5-27B, DeepSeek-chat, and GPT-4o-mini. CABLE yields higher mean LLM-judge scores in every evaluated system-level setting, with the largest gains in categories where useful evidence is distributed across memories or sessions, including open-domain, multi-session, and preference-oriented questions. These results support prioritizing sparse, reasoning-relevant associations that complement rather than duplicate the host retriever.

# 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

LLM 智能体系统正日益组织为执行图（execution graphs）形式，由专门组件和显式状态转换构成。随着这些系统跨组件和会话边界运行，长期历史无法再假设保留在单个提示中，由此引发**证据可达性问题（evidence-reachability problem）**：执行图指定了计算的流动方式，但并不能保证后续组件能在有界上下文内恢复相关的历史信息。

论文聚焦于长期会话记忆中的证据可达性具体实例。当前记忆系统（如 Mem0、A-MEM 等）通常将过去交互存储为紧凑的记忆条目，并针对每个新查询检索一小部分。**语义相似性检索**在查询与所需记忆在嵌入空间中接近时效果良好，但在以下情况失效：查询涉及较晚事件，而回答它需要较早记忆中关于经验、计划、动机或背景事件的信息。此时所需证据存在但无法被检索器的有限输出预算所触及。

论文进一步指出，现有记忆图方法（A-MEM、Mem0g、HippoRAG 等）提供的关联如果主要反映语义重叠、共享实体或邻近描述，则图扩展可能只是返回宿主检索器已能覆盖的记忆——在固定上下文预算下，冗余邻居会挤占更有用证据的空间。因此，作者提出**检索器互补性（retriever complementarity）**作为记忆图的设计准则：关联的价值在于暴露宿主检索器直接邻域之外的有用证据，而非一味追求全面的世界模型。

## 2. 方法论

### 核心思想

CABLE（Complementary Antecedent-Based Linking and Expansion）作为一个插件式增强模块，通过构建并复用**稀疏的、经验证的、基于前因的互补关联**来扩展宿主记忆检索器的直接语义覆盖范围。其核心原则是：链接应补充而非复制宿主检索器的功能。

### 技术细节与算法流程

#### 构建阶段（Construction-time antecedent link building）

对于每条新到的记忆 $m_i$，CABLE 通过四步构建从先前记忆到 $m_i$ 的有向边：

1. **前因导向的查询生成（Antecedent-oriented query generation）**：
   - 规则过滤去除问候等低信息记忆；
   - LLM 将记忆分类为 `event`、`opinion`、`plan` 或 `state change` 四种操作类型；
   - 依据类型生成 $N_q = 3$ 个前因导向查询 $Q(m_i) = \{q_1, \ldots, q_{N_q}\}$，聚焦于先前的经验、原因、动机、背景等。

2. **双路检索（Dual retrieval）**：
   - **直接搜索**：$B_i$ 包含与 $m_i$ 嵌入余弦相似度最高的前 $K_b=15$ 条记忆，作为直接语义邻域；
   - **前因搜索**：对每个 $q \in Q(m_i)$ 分别检索，合并得到 $H_i$（每条记忆保留最高分），$K_h=15$。

3. **重叠扣除（Overlap subtraction）**：
   - $C_i = H_i \setminus B_i$，排除已处于直接语义检索范围内的候选，只保留检索器互补候选。若 $C_i = \emptyset$，则不添加边。

4. **验证与图更新（Verification and graph update）**：
   - LLM 验证器检查候选 $m_j \in C_i$ 是否为有用的先前上下文（如原因、动机、使能事件、背景事件或更早状态），拒绝仅靠主题共现或实体重叠的关联；
   - 接受的配对添加有向边 $E \leftarrow E \cup \{(m_j \to m_i)\}$，表示验证过的前因链接。

#### 检索阶段（Retrieval-stage extension）

1. **种子选择**：从宿主结果集 $R_0$ 保留 $\text{sim}(\phi(q), \phi(s)) \geq \tau$（$\tau = 0.3$）的可靠种子 $S$；
2. **候选评分**：对每个种子 $s$ 的一跳邻居 $N(s)$（含入边和出边）形成候选池 $U$，剔除 $R_0$ 中已有项，按 $\text{score}(c) = \sum_{s} \text{sim}(\phi(c), \phi(s))$ 聚合打分；
3. **新颖性过滤**：贪心选择候选至扩展预算（5 条），仅当与当前结果集最大相似度 $\max_{r \in R} \text{sim}(\phi(c), \phi(r)) < \theta$（$\theta = 0.9$）时接受。

#### 关键特性

- 构建阶段的前因推理在记忆写入时一次性完成，链接在后续检索中复用；
- 检索时扩展**无需额外 LLM 调用**；
- 图规模以 $|E| = O(|M|)$ 线性增长；
- 在 A-MEM 和 Mem0g 集成中，CABLE 在固定检索条目预算下替换排名最低的基线条目（最多 5 条），而非追加额外上下文。

## 6. 主要结论与发现

1. **A-MEM 集成下 CABLE 在所有设置中均提升**：LoCoMo 上 +2.11~+3.58 pp，MA-LongMemEval 上 +1.00~+6.00 pp。
2. **增益最大的场景与假设一致**：LoCoMo 的 Open-domain 类别增益最大（+6.24 / +9.37 pp）；MA-LongMemEval 的多会话（+12.00 / +2.66 pp）和偏好类（+23.33 / +3.33 pp）增益显著——这些类别恰好需要跨记忆或跨会话的隐式关联。
3. **跨系统泛化有效**：SimpleMem 提升 +0.58 / +1.62 pp（自适应激活），Mem0g 提升 +2.20 pp（固定预算），表明互补性原则不依赖特定宿主架构。
4. **组件消融验证设计**：重叠扣除和验证均有助于性能；类型条件化的前因查询优于通用查询分解。
5. **定性案例证明机制价值**：语义检索返回主题相关但缺乏信息量的记忆，CABLE 沿存储的前因链接恢复了解释动机的关键记忆。

## 7. 优点

- **问题定义精准**：明确区分"存储了历史"与"能恢复证据"两个概念，聚焦证据可达性这一实际且未被充分解决的问题。
- **设计原则清晰**：提出"检索器互补性"准则——图链接的价值以其边际检索贡献衡量，而非图结构的完整性。这一原则具有较强普适性和可操作性。
- **成本控制巧妙**：构建成本按记忆数线性增长、检索阶段零额外 LLM 调用、图规模线性增长（$|E|=O(|M|)$），工程上可行。
- **实验对照组严谨**：通过"替换而非追加"保持固定检索预算的多系统集成协议，基线对比公平。
- **跨架构验证充分**：三种架构差异显著的宿主系统均获得增益，消除了单宿主依赖。
- **透明可解释**：链接为显式、可检查的有向边，附验证理由，定性案例增强了方法可理解性。

## 8. 不足与局限

- **时间推理受损**：MA-LongMemEval 的 temporal-reasoning 类别出现一致下降（-1.33~-2.67 pp），说明联想式扩展对需要精确时间解析的任务可能引入干扰，方法缺乏针对时间约束的机制。
- **图无遗忘与修正**：构建为 append-only，边一旦插入即持久存在；后续记忆可能使早期链接过时或冗余，缺少遗忘/衰减/合并策略，长期运行时可能积累噪声。
- **知识更新场景增益有限**：A-MEM 知识更新类别在 Qwen3.5-27B 下无变化（0.00），对需要整合新信息覆盖旧信息的场景，CABLE 帮助有限。
- **评估范围受限**：仅限长程会话记忆 QA，未覆盖工具使用智能体、多智能体协调或图级任务执行；消融的通用查询分解仅在一侧基准实施。
- **对基础检索质量敏感**：CABLE 的种子选择依赖宿主检索器的初始结果，若宿主检索者初始返回质量低，扩展的有用性可能受到影响。
- **LLM judge 的主观性**：采用同一模型的 LLM 评判可能有偏见，未使用人工评估或基于参考的客观指标交叉验证。
- **计算成本信息缺失**：未报告 GPU 资源和推理延迟等实际部署成本，难以评估端到端额外开销的工程可接受性。
