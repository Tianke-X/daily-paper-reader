## 摘要
用于改进大型语言模型知识使用的方法通常分为两种模式。非参数检索提供对外部知识的灵活访问，但增加了检索延迟、上下文开销，并且与主干的集成较浅。参数化适应在推理时高效，但将知识与模型权重交织在一起，难以更新、审计或迁移。Engram式哈希记忆占据了中间模式：它将学习到的信息存储在外部可寻址表中，但通过一个小型学习读取器来使用该表。这引发了一个基本问题：当这样的记忆跨主干移动时，更重要的是冻结的记忆本身还是目标侧读取器？我们通过跨模型冻结记忆提取来研究这个问题，其中在源模型上训练的记忆被冻结并附加到不同的目标模型上，仅训练一个轻量级读取器。消融实验表明，学习到的记忆内容和正确的寻址都很重要，但转移的表只有通过与目标模型对齐的读取器才能变得有用。在下游问答任务中，一个双层四分支读取器几乎弥合了同模型和跨模型重用之间的差距，在我们受控评估协议下平均得分38.8。此外，当提供者读取器与目标接口直接兼容时，冻结产物可以无需目标侧训练即可提供实质性效用，而可选读取器适配则带来进一步改进。这些结果表明，只要目标能够访问兼容的读取器接口，Engram就可以作为可重用的外部知识产物；当直接复用读取器不足时，目标侧适配可以进一步改善对齐。

## Abstract
Methods for improving knowledge use in large language models typically fall into two regimes. Non-parametric retrieval offers flexible access to external knowledge, but adds retrieval latency, context overhead, and only shallow integration with the backbone. Parametric adaptation is efficient at inference time, but entangles knowledge with model weights and can be hard to update, audit, or transfer. Engram-style hashed memory occupies a middle regime: it stores learned information in an external, addressable table, yet consumes that table through a small learned reader. This raises a basic question: when such a memory is moved across backbones, what matters more, the frozen memory itself or the target-side reader? We study this question through cross-model frozen-memory extraction, in which a memory trained on a source model is frozen and attached to a different target model, with only a lightweight reader trained. Ablations show that learned memory content and correct addressing both matter, but the transferred table becomes useful only through a reader aligned to the target model. In downstream question answering tasks, a dual-layer, four-branch reader nearly closes the gap between same-model and cross-model reuse, achieving an average score of 38.8 under our controlled evaluation protocol. Moreover, when the provider reader is directly compatible with the target interface, the frozen artifact can provide substantial utility without target-side training, while optional reader adaptation yields further improvement. These results suggest that Engram can serve as a reusable external knowledge artifact, provided that the target has access to a compatible reader interface; target-side adaptation can further improve alignment when direct reader reuse is insufficient.

## 论文核心问题与整体含义

**研究动机与背景背景**
- 大型语言模型（LLMs）的知识增强方法主要分为两大范式：
  - **非参数检索**（如RAG、kNN-LM）：灵活访问外部知识，但引入检索延迟、上下文开销，且与骨干模型集成较浅。
  - **参数化适应**（如继续预训练、微调）：推理时高效，但知识嵌入模型权重，难以更新、审计和跨模型迁移。
- **Engram式哈希记忆**代表第三条路径：将学习到的信息存储在外部、可寻址的表中，通过小型可学习读取器（reader）消费该表。它兼顾外部模块化与学习表示的效率。
- 由此引出一个核心问题：当记忆从源模型迁移到目标模型时，**冻结的记忆本身**与**目标侧读取器**，究竟谁更重要？记忆是否真正可移植，还是仅仅是源模型的"共适应扩展"？
- 该问题的答案具有实质意义：若记忆表不可移植，则它只是模型特定参数的另一种形式，而非可重用的知识基板。

## 方法论：核心思想、关键技术细节、流程

**核心思想**
- 将Engram记忆重铸为**可迁移的工件（artifact）**：冻结源记忆表，仅训练轻量级目标侧读取器进行提取和对齐。
- 将记忆系统解构为三个独立角色：**寻址（addressing）**——决定读取哪个条目；**存储（memory）**——存储的向量本身；**读取（reader）**——将检索向量映射进目标模型。
- 研究主张：**可移植的哈希外部记忆中，仅靠记忆存在不够，成功复用取决于目标骨干读取和消费存储表示的接口；但记忆内容同样重要。**

**关键技术细节**

1. **Tokenizer无关的规范化寻址**
   - 原生Engram使用模型特定的token ID进行哈希，跨模型时相同文本会路由到不同记忆槽位。
   - 本文改为基于**规范化解码文本**构建查找空间：对解码前缀执行NFKC规范化、小写化、去重音符号和空白清理，再按词边界n-gram进行确定性哈希。
   - 对无可靠空格分割的语言（中日文），改用规范化的Unicode字符跨度进行哈希。
   - 公式表达：$e_t = \bigoplus_{n=2}^{N} \bigoplus_{j=1}^{K} E_{n,j}[\phi_{n,j}(w_{m(t)-n+1}, \ldots, w_{m(t)})]$

2. **目标侧读取器（Reader）设计**
   - 采用共享值投影的多分支读者族，分支数R控制对齐能力而不增加记忆规模：
     - 每个分支有独立的关键投影 $W_{K,\ell,r}^{(B)}$ 和上下文感知门控
     - 共享值投影 $W_{V,\ell}^{(B)}$ 使分支间共享检索内容
   - 门控公式：$\alpha_{t,\ell}^{(r)} = \sigma\left(\frac{\text{RMSNorm}(h_{t,\ell})^\top \text{RMSNorm}(k_{t,\ell}^{(r)})}{\sqrt{d_B}} + \beta_{\ell,r}\right)$
   - 读取器输出通过残差连接注入：$h_{t,\ell} \leftarrow h_{t,\ell} + o_{t,\ell}$，其中 $o_{t,\ell} = \frac{1}{R}\sum_{r=1}^{R} \alpha_{t,\ell}^{(r)} \cdot v_{t,\ell}$
   - 支持单层或双层注入（QA最优配置为层2和层10、R=4分支）

3. **两阶段训练协议**
   - **Phase 1（源侧记忆训练）**：在源模型上以标准下一token预测目标训练Engram记忆，训练结束后冻结源骨干和记忆表。
   - **Phase 2（目标侧读取器适配）**：冻结目标骨干和迁移的记忆表，仅更新读取器参数，继续用下一token预测损失。
   - **两种部署模式**：
     - **直接工件复用**：提供者导出冻结记忆+兼容读者，消费者零训练。
     - **读者适配复用**：相同冻结记忆，但拟合轻量目标特定读者。

   - 算法流程（Algorithm 1）：提取记忆表→冻结→初始化目标侧读者并注册hooks→规范化输入→查表检索→前向计算→仅更新读者参数

## 主要结论与发现

1. **冻结记忆确可跨模型迁移**：3×3迁移矩阵全部9个单元均显示PPL改善（1.6%至15.7%），最强增益为Qwen3.5-0.8B → TinyLlama-1.1B（-15.7%），跨架构和tokenizer差异时依然成立。对等迁移（Phi→Qwen、Qwen→Phi）双向均有效。

2. **读者设计是迁移质量的一阶决定因素**：双层注入将QA准确率从34.2提升至37.5，多分支门控进一步升至38.5；单层冻结读者仅达33.5。迁移表格的有效性高度依赖目标侧读者的对齐能力。

3. **跨模型与同模型重用几乎持平**：最强配置（{2,10}-R4）下，同模型与跨模型QA准确率完全相同（38.5 vs 38.5），30/30预算下可达38.8，实现SoTA。

4. **迁移效用是任务依赖的**：对事实型任务（RTE、SciQ、BoolQ）增益稳定正面；对RACE几乎无影响；对TruthfulQA在各规模均轻微负面（-0.2至-0.8），说明校准型任务可能受记忆关联干扰。

5. **传输不靠参数数量，而靠寻址与读者**：参数匹配的FFN取得最低PPL（7.4），但QA仅34.5（落后4.0分）；随机记忆PPL与传输相同（8.7），但QA低于后者4分；Permuted keys造成最大降级（38.5→32.5）。

6. **传输的优势在初始化而非渐近上限**：从零训练的scrach记忆最终匹配传输性能（38.4 vs 38.5），但需要更多训练数据；传输记忆在5M tokens即竞争，20M tokens基本饱和。

7. **答案token支持分析**：传输记忆在NQ、WebQA、TriviaQA、HotpotQA上增加了金标准答案的log-probability，但答案位置消融效应接近零——说明增益来自改善的整体事实支持状态，而非直接的答案token注入。

## 方法或实验设计的亮点

- **问题形式化清晰**：将"记忆可移植性"从模糊概念转化为操作化问题——"目标模型能否学习读取固定记忆工件"——并分离寻址、存储、读取三种角色分别检验。
- **Tokenizer无关寻址**：用解码文本规范化代替token ID哈希，解决了跨tokenizer迁移的根本障碍；对中日文设计字符跨度变体，扩展了方法适用范围。
- **控制对照组设计严谨**：
  - "随机记忆+读者"区分存储与接口的作用
  - "Permuted keys"孤立寻址完整性的贡献
  - "参数匹配FFN"排除参数数量解释
  - "Mem-only"证明无读者的记忆不可用
  - 多组实验从不同角度验证同一结论
- **"冻结读者"模式的发现**：当提供者读者与目标接口直接兼容时，冻结工件无需目标侧训练即可提供~38.3的QA成绩（基线32.1），揭示了一种新的部署模式——记忆工件可作为真正可移植、零训练成本的知识资源传递。
- **CKA表征分析**：显示表征相似性不预测迁移增益（Pythia→TinyLlama CKA仅0.013却取得10.6%改善），进一步支撑"读者提取能力而非表征对齐"的核心主张。
- **OOD和分布偏移探测**：检验了读者适配后是否损害无关分布的语言建模（整体中性），以及读者训练-评估语料失配时迁移是否仍然有效（四种条件下均有效）。

## 不足与局限性

**实验覆盖的局限**
- **规模上限**：源和目标模型最大仅至9B参数；未验证更大模型（如70B+）下读者容量是否需随骨干扩展，未建立读者结构（深度、分支数、注入位置、参数）与主干的扩展律。
- **语言覆盖**：默认词边界寻址仅对空格分隔语言（英语类）有效；中日文需改用字符跨度方案，但尚未解决代码、噪声Unicode、混合脚本、字节级tokenizer等更复杂场景。
- **读者设计空间**：仅评估线性读者、单/双层注入和最多4分支；非线性变换、自适应分支聚合、层相关值投影、可学习注入位置等可能进一步提升提取能力，但会模糊"可重用记忆内容"与"读者新增容量"的边界。
- **门控的作用**：上下文感知门控对某些源-目标分布组合作用显著（移除使QA降低4.8分），但门控何时必需、何时简单读者足够，缺乏系统研究。

**偏差风险**
- **基准模型预训练语料未知**：无法完全排除下游评测的污染，作者明确将结果定位为"受控比较"而非"无污染SoTA声明"。
- **种子数量有限**：部分实验仅3个种子，且部分种子信息未在正文中完整报告。
- **不同实验使用不同读者配置**：主迁移矩阵用单层R=1，QA实验用双层R=4，跨实验比较性能时需注意协议差异。
- **Phase-1和Phase-2语料的映射**：不同实验组合了不同源/目标语料对，结果比较时需仔细对照附录中的配置表。

**应用限制**
- **需要目标侧适配数据和算力**：读者适配模式仍依赖于目标侧训练数据流和额外算力（即使远小于全量训练）；直接复用模式要求读者接口与目标残差流维度兼容，限制了通用性。
- **TruthfulQA的负面效应**：记忆迁移可损害校准型任务，用户需谨慎选择适用场景；混合记忆虽能保持专家增益，但"何时混合"的指导原则尚未明确。
- **摊销门槛**：在约9-11个适配消费者之后，传输方案才在累计成本上优于逐个从头训练记忆——对少量消费者场景的经济性尚存疑问。

## 总结性评价（续）

该论文以清晰的实验链系统回答了"冻结的外部哈希记忆能否跨模型迁移"这一核心问题，并给出了**有条件肯定的答案**：记忆内容与读取器接口二者缺一不可，但传输增益的真正瓶颈在目标侧读取器的提取能力，而非记忆表本身的可移植性。论文通过严格的控制变量设计（参数匹配FFN、随机记忆、Permuted keys、Mem-only崩溃对照组），将"记忆迁移"这一宏观现象拆解为寻址、存储、读取三个可独立检验的机制维度，使结论具备较强的内部效度。整体而言，这是一项**实验设计严谨、问题定义清晰、结论具有可操作性的高质量实证研究**。

## 创新性与学术贡献评估

**理论层面**
- 首次系统定义了Engram式记忆的"可移植性"问题，并区分了记忆内容可迁移性与读者适配能力两个概念——这一区分对记忆增强LLM领域具有概念澄清价值。后续研究者可将"记忆是否可移植"的争论转化为"在何种读者架构下记忆可移植"的可量化问题。
- 对CKA表征相似度与迁移增益之间关系的负向发现（Pythia→TinyLlama CKA仅0.013却取得10.6%改善），挑战了"表征对齐是迁移前提"的直觉假设，为理解跨架构知识传输提供了新的理论视角。

**方法层面**
- Tokenizer无关的规范化寻址方案解决了跨tokenizer迁移的根本技术障碍，这一贡献独立于记忆可移植性结论本身，可被其他记忆增强框架直接采用。
- 两阶段训练协议（Phase-1源侧记忆训练→Phase-2目标侧读者适配）将记忆生产与记忆消费解耦，类似于"预训练-微调"范式在记忆领域的对应物，具备工程可复用性。

**实践层面**
- "冻结工件直接复用"模式（~38.3 QA成绩、零训练成本）展示了记忆作为独立知识资产分发的可能性——模型持有者可以像分发模型权重一样分发记忆表，而消费者无需任何训练即可获得质量增益。
- 数据效率分析（5M tokens即竞争、20M tokens接近饱和）为实际部署提供了明确的资源规划依据。

## 对后续研究的启示

1. **读者架构的扩展空间**：论文中线性读者仅覆盖了极小一部分设计空间。未来可探索非线性读者、跨层注意力式读者、可学习注入位置、记忆条目的稀疏聚合等方案，但需注意维持"记忆内容冻结"的约束以保持可移植性声明的纯洁性。

2. **更大规模的验证需求**：读者容量与骨干规模之间是否存在可预测的扩展律（scaling law），是该方法能否走向70B+乃至更大模型的关键未决问题。论文的9B上限限制了这一判断。

3. **记忆内容与读者的联合优化**：论文表明READER是性能瓶颈，但MEMORY（随机记忆QA落后4分、Permuted keys降级6分）同样不可忽略。未来可探索在Phase-1阶段即为"可迁移性"优化的记忆训练目标（如显式鼓励与模型无关的表征），而非仅用标准语言建模目标。

4. **多语言与多模态扩展**：字符跨度寻址对中日文的处理仍属初步方案，字节级tokenizer、混合脚本和代码场景的寻址策略尚待研究；多模态记忆中"文本锚定"思路的适用性也是开放问题。

5. **混合记忆的部署策略**：论文指出混合记忆可保持专家增益而不损害通用能力，但"何时混合、混合比例如何确定"缺乏系统指导，是直接的后续课题。

## 总体评价与推荐阅读建议

**优点**：问题聚焦、实验链完整、控制严谨、消融全面、算力报告透明；在"记忆可移植性"这一此前鲜有严格实证的话题上，提供了迄今最系统的证据。

**缺点**：规模上限较低、部分实验种子信息不完整、不同实验间读者配置不一致带来比较复杂度、基准语料污染风险未完全排除；对"何时此方法优于RAG/参数化适应"的工程选型指导有限。

**适合读者**：从事知识增强LLM、持续学习、模型复用与迁移学习研究的研究者；对记忆系统架构设计感兴趣的工程师。不建议作为"记忆优于RAG/微调"的结论性文献引用——论文自身的定位是受控条件下机制理解的实证研究。

**一句话概括**：这篇论文以教科书级别的消融设计证明了"冻结的外部记忆可以跨模型迁移，但迁移成败取决于目标侧读取器这一'接口'，而非记忆本身"——它没有发明最强的记忆系统，但为记忆系统的可移植性奠定了第一块坚实的实证基石。
